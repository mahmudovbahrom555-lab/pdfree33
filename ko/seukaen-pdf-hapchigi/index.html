스캔 PDF도 일반 PDF 파일입니다

스캔 PDF는 페이지가 텍스트가 아니라 이미지(PDF 컨테이너에 삽입된 JPEG 또는 PNG)로 구성된 PDF일 뿐입니다. 합치기 관점에서 스캔 PDF와 텍스트 PDF는 완전히 동일하게 작동합니다 — 스캔 페이지와 텍스트 페이지를 어떤 순서, 어떤 조합으로든 결합할 수 있습니다. PDFree는 특별한 설정 없이 두 가지 모두 처리합니다.

위 도구에 스캔 PDF를 드롭하고 순서를 정렬한 다음 합치기를 클릭하세요. 결과물은 어떤 PDF 뷰어에서도 열리는 표준 PDF 파일입니다.

스캔 PDF를 합치는 일반적인 상황

🖨️
한 페이지씩 스캔한 여러 페이지 문서 — 스캐너가 각 페이지마다 개별 PDF 파일을 생성하는 경우. 모두 하나의 완전한 문서로 합치세요.
📝
페이지별로 스캔한 실물 계약서 — 흩어져 있는 스캔 계약서 페이지들을 서명 가능한 하나의 문서로 모으세요.
📅
서로 다른 스캔 세션의 페이지 결합 — 오늘 스캔한 페이지와 지난주에 스캔한 추가 페이지가 있다면, 두 그룹을 하나의 통합 문서로 합치세요.
🧾
스캔한 인보이스나 영수증 아카이브 — 매월 스캔한 인보이스를 회계나 감사를 위한 연간 아카이브 파일 하나로 결합하세요.

파일 크기와 페이지 수

스캔 PDF는 각 페이지가 전체 해상도 이미지로 저장되기 때문에 텍스트 PDF보다 일반적으로 용량이 큽니다. A4 페이지의 300 DPI 스캔은 페이지당 약 1-3MB이며, 100페이지 스캔 문서는 100-300MB에 이를 수 있습니다. PDFree는 처리가 서버가 아닌 브라우저에서 이루어지므로 파일 크기 제한이 없습니다. 실질적인 제한은 기기의 사용 가능한 RAM뿐입니다.

스캔 PDF의 일반적인 RAM 사용량
  • 8GB RAM: 50-100페이지 스캔(100-300MB)을 편안하게 처리
  • 16GB RAM: 300-500페이지 스캔 또는 수백 MB 처리
  • 대용량 배치(500페이지 이상): 합치기 전에 다른 브라우저 탭을 닫아 RAM을 확보하세요

합친 후: PDF를 검색 가능하게 만들기

스캔 PDF를 합친 후, 텍스트를 선택하고 검색할 수 있도록 OCR(광학 문자 인식)을 실행하고 싶을 수 있습니다. PDFree의 OCR 도구(pdfree.io/ocr-pdf/)는 합쳐진 파일을 브라우저에서 완전히 처리할 수 있습니다 — 업로드가 필요 없습니다. OCR은 각 스캔 페이지 위에 투명한 텍스트 레이어를 추가하여, 원본 스캔은 그대로 보이면서 텍스트는 검색 및 복사가 가능해집니다.

스캔 문서를 위한 권장 작업 순서:

  1. 모든 스캔 페이지 합치기 → 하나의 결합된 PDF (이 도구)
  2. 합친 파일에 OCR 실행 → 검색 가능한 텍스트 레이어 (pdfree.io/ocr-pdf/)
  3. 파일이 전송하기에 너무 크면 압축 (pdfree.io/ko/pdf-apchuk/)

자주 묻는 질문

합친 스캔 PDF가 왜 이렇게 용량이 큰가요?

스캔한 페이지는 전체 해상도 이미지로 저장됩니다 (300 DPI 스캔 ≈ 페이지당 1-3MB). 합친 후 pdfree.io/ko/pdf-apchuk/를 사용해 용량을 줄이세요 — 압축은 이미지가 많은 스캔 PDF에서 특히 효과적이며, 종종 50-70% 용량이 줄어듭니다.

스캔 PDF와 텍스트 PDF를 함께 합칠 수 있나요?

네. PDFree는 스캔 PDF와 텍스트 PDF의 어떤 조합이든 합칠 수 있습니다. 결과물은 각 페이지를 그대로 유지합니다 — 스캔 페이지는 이미지로, 텍스트 페이지는 선택 가능한 텍스트로 남습니다.

스캔 PDF를 합칠 때 페이지 수 제한이 있나요?

페이지 수 제한은 없습니다. PDFree는 브라우저에서 파일을 로컬로 처리합니다. 실질적인 제한은 기기의 사용 가능한 RAM입니다 — 최신 기기는 수백 페이지의 스캔본도 문제없이 처리합니다.

합치기 전에 페이지 순서를 바꿀 수 있나요?

네 — 합치기를 클릭하기 전에 원하는 순서로 파일을 드래그하세요. 각 파일은 별도 항목으로 표시되며 드래그로 순서를 바꿀 수 있습니다.

합친 후 스캔 PDF의 텍스트를 선택 가능하게 하려면 어떻게 하나요?

합친 PDF를 pdfree.io/ocr-pdf/에 통과시키세요 — OCR 도구가 원본 스캔을 그대로 보여주면서 스캔 페이지에 검색 가능한 텍스트 레이어를 추가합니다.
