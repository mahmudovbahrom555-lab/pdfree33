Warum „Kein Upload“ Wichtig Ist

Wenn du Tools wie iLovePDF oder SmallPDF nutzt, reisen deine Dateien übers Internet zu einem entfernten Server. Dieser Server verarbeitet sie, speichert sie vorübergehend (für 1–2 Stunden) und löscht sie dann. Während dieses Zeitfensters existieren deine Dokumente auf dem Computer eines Fremden.

Für alltägliche Dateien wie Besprechungsagenden ist das unproblematisch. Aber für Kontoauszüge, medizinische Unterlagen, Verträge, Steuererklärungen oder Ausweisdokumente — der Upload zu einem fremden Server schafft unnötige Risiken. Ein Server-Breach, eine falsch konfigurierte Berechtigung oder eine behördliche Anordnung könnte deine Dokumente offenlegen.

Der Ansatz von PDFree: Deine Dateien werden in den Arbeitsspeicher deines Browsers geladen, mit einer JavaScript-Bibliothek (pdf-lib) zusammengeführt, und das Ergebnis wird lokal erzeugt. Schließe den Tab — die Dateien sind weg. Es gibt keinen Server. Es gibt nichts zu kompromittieren.

Häufig Gestellte Fragen

Lädt PDFree meine PDF-Dateien auf einen Server hoch?

Nein. PDFree führt PDFs vollständig in deinem Browser mit pdf-lib zusammen. Deine Dateien werden nie über das Internet gesendet. Du kannst das überprüfen, indem du DevTools → Netzwerk öffnest — du siehst null Anfragen mit deinen PDF-Daten.

Ist es sicher für medizinische Unterlagen und juristische Dokumente?

Ja. Da Dateien dein Gerät nie verlassen, ist PDFree sicher für streng geschützte medizinische Unterlagen, privilegierte juristische Dokumente und jeglichen anderen sensiblen Inhalt. Es gibt keinen Server, der kompromittiert werden könnte.

Wie unterscheidet sich das von iLovePDF oder SmallPDF?

iLovePDF und SmallPDF laden deine Dateien auf ihre Server hoch, verarbeiten sie dort und löschen sie nach 1–2 Stunden. PDFree verarbeitet alles lokal — deine Dateien reisen nie zu einem Server. Du bekommst außerdem keine Dateigrößenlimits und keine Tageslimits.

Gibt es ein Dateigrößenlimit?

Nein. PDFree hat keine Dateigrößenbeschränkung, da die Verarbeitung lokal erfolgt. Der Arbeitsspeicher deines Geräts ist die einzige Einschränkung — moderne Geräte verarbeiten PDFs bis zu mehreren hundert Megabyte problemlos.

Kann ich PDFs vollständig offline zusammenführen?

Ja. Nach deinem ersten Besuch wird PDFree als PWA zwischengespeichert und funktioniert vollständig offline — für die Verarbeitung ist keine Internetverbindung nötig.

Ist PDFree DSGVO-konform?

PDFree ist durch seine Architektur DSGVO-sicher: Es werden nie Gesundheits- oder personenbezogene Daten an unsere Server übertragen, weil es keine serverseitige Verarbeitung gibt. Beschäftigte im Gesundheitswesen können PDFree sicher für patientenbezogene Dokumente nutzen.
