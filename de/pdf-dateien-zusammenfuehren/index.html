FAQ

Wie viele PDF-Dateien kann ich gleichzeitig zusammenführen?

Es gibt kein Limit. PDFree führt Dateien vollständig in Ihrem Browser zusammen — das praktische Limit ist der verfügbare RAM Ihres Geräts. Die meisten Nutzer führen problemlos 20–50 Dateien zusammen.

Kann ich die Reihenfolge der Dateien vor dem Zusammenführen ändern?

Ja. Ziehen Sie die Dateien in der Liste per Drag-and-Drop, um sie neu anzuordnen. Die zusammengeführte PDF folgt der angezeigten Reihenfolge. Touch-Drag wird auf Mobilgeräten ebenfalls unterstützt.

Verringert das Zusammenführen die PDF-Qualität?

Nein. Das Zusammenführen ist verlustfrei — Bilder, Schriften und Vektorgrafiken bleiben in Originalqualität erhalten. Es findet keine Neukodierung statt.

Sind meine Daten beim Zusammenführen privat?

Vollständig. Alle Verarbeitungen finden in Ihrem Browser statt. Keine Datei wird jemals auf einen Server übertragen — Ihre Dokumente verlassen nie Ihr Gerät.
