Password Protect PDF — AES-256 Encryption, Files Stay Local

Add password protection and usage restrictions to your PDFs. PDFree uses RC4-128 encryption (compatible with all PDF readers) to secure documents with a user password for opening and owner password for permissions. All encryption happens in your browser — your password and document never touch a server.

Two Types of Protection

Open Password (User Password): Required to view the document. Without this password, the PDF cannot be opened in any reader. Use this for truly confidential documents.

Owner Password (Permissions Password): Controls what users can do with the document even after opening. Restrict printing, copying text, editing content, adding comments, filling forms, or rotating pages.

You can set both passwords or just one. If you only set permissions without an open password, the document is viewable by anyone but usage is restricted.

Permission Control

Choose exactly what users can do:

  • Print: Allow or deny printing the document
  • Copy Text: Enable or block text selection and copying
  • Edit: Control whether content can be modified
  • Annotate: Allow or prevent adding comments, highlights, or notes
  • Fill Forms: Enable or disable filling interactive form fields
  • Assemble: Control page insertion, deletion, or rotation

Quick Presets

🔓 Open Only: Password required to open, but all operations allowed inside. Use when you want to control access but not usage.

📖 Read-Only: Users can view and print, but cannot copy, edit, or comment. Perfect for distributing reports or documentation you want read but not modified.

🏰 Fort Knox: Maximum restrictions. No printing, no copying, no editing. Useful for watermarked drafts or confidential previews.

Encryption Technical Details

PDFree uses RC4-128 encryption, the same algorithm used by Adobe Acrobat for decades. RC4-128 provides:

  • Universal compatibility: Supported by all PDF readers (Adobe Reader, Preview, Chrome, Firefox, mobile apps)
  • 128-bit security: Strong enough for most business and personal use
  • Fast processing: Encryption happens instantly in browser JavaScript

For context: 128-bit encryption means 2¹²⁸ possible keys (340 undecillion combinations). Even with modern computing, brute-forcing a strong password is computationally infeasible.

⚡ Password Strength: Use the built-in password generator (⚡ button) for cryptographically random 16+ character passwords. Store passwords in a password manager — if you lose the password, the PDF is unrecoverable.

Privacy & Security

Encryption happens entirely in your browser using pdf-lib's built-in RC4 implementation. Your password and document content never leave your device. This is critical — even HTTPS-encrypted transmission to a server means the server momentarily has access to your unencrypted file and password.

PDFree generates the encryption keys in-browser, encrypts the PDF content, and outputs a protected file directly to your download folder. No intermediate storage, no server logs, no password recovery system (because we never see your password).

Use Cases

Legal: Protect contracts, NDAs, or settlement agreements during negotiation phases. Share drafts with "no printing" permissions to prevent unauthorized distribution.

Financial: Secure tax returns, bank statements, or investment reports before emailing to accountants or advisors.

Medical: Encrypt health records or test results when sharing via email. Ensure HIPAA compliance by preventing unauthorized forwarding (permissions control).

Business: Distribute read-only reports, presentations, or proposals. Prevent competitors from copying your content while still allowing client viewing.
