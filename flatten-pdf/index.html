Flatten PDF — Make Fillable PDF Non-Editable Online

Filled in a form and need to lock it before sending? Flattening bakes the values directly into the page — fields become plain text, no one can alter the data, and the document looks identical on every device and viewer.

When You Need to Flatten a PDF

Government and court portals reject your upload

Systems like CM/ECF (US federal courts), NIH grants, and many government e-filing portals explicitly require a "flattened PDF." If the portal returns an error about form fields, this tool fixes it.

Sending a contract or agreement

After both parties have filled in their details, flatten the document before final distribution. This prevents anyone from quietly editing a field value after the fact.

Preparing for print or long-term archiving

Flattened PDFs render identically in every viewer, printer, and archival system. Form layers and transparency effects that cause printing glitches are eliminated.

Recipient's PDF viewer shows empty fields

Some viewers (older Acrobat versions, built-in browser PDF viewers, iOS Preview) don't render AcroForm field content. Flattening bakes the values into the page so they appear everywhere.

Frequently Asked Questions

What exactly happens to the form fields?

Each field's current value is rendered as static text or image directly on the page content stream. The interactive field annotation (the object that makes it editable) is then removed from the PDF. The result looks identical but contains no editable layer.

Is this different from adding a password to a PDF?

Yes. A password restricts access to the file. Flattening removes the form structure — the file stays fully readable but the fields are gone. For maximum protection, use Protect PDF to add a password after flattening.

What happens if my PDF has no form fields?

If the PDF is already flat (no editable fields), the file is returned to you unchanged and a notice appears. This is not an error — the file is just already in the state you want.

Does flattening reduce file size?

Usually slightly, yes. Removing form annotations and their associated resources (fonts, appearance streams) can trim a few kilobytes. The difference is rarely significant for typical forms.

My form uses Adobe LiveCycle (XFA) — will this work?

No. XFA is a proprietary Adobe format that requires Acrobat Pro to flatten. Our tool supports AcroForm, which is the standard format used by the vast majority of modern fillable PDFs (IRS forms, government forms, most legal templates). If you're unsure which format your PDF uses, try the tool — you'll get a clear message if XFA is detected.
