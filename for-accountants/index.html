Frequently Asked Questions

Can I batch compress or password-protect client statements without merging them?

Yes. Batch mode on Compress and Protect keeps each file separate — it applies the same setting to every file you select and returns them as individual files inside one ZIP, not combined into a single document. See the full batch processing guide for all supported tools.

Is it safe to process client financial data with a free online tool?

With PDFree, yes. No file is transmitted to any server. Account numbers, tax IDs, and financial figures stay in your browser's memory and are cleared when you close the tab. Most other free PDF tools upload your document — check their privacy policy before processing financial data with them.

Can I merge 80 invoices at once without a file size limit?

Yes. PDFree has no file count limit and no file size cap. Drop all invoices at once — 10, 50, or 100 — arrange them in order, and click Merge. The only practical limit is your device's available RAM. A modern computer handles 100 invoices totalling several hundred megabytes without issues.

Does PDFree work offline — can I process files without an internet connection?

Yes. Once the page has loaded at least once, PDFree functions as a Progressive Web App and works fully offline. This is useful for processing sensitive financial documents on a device not connected to the internet.
