Diviser un PDF en Ligne — Gratuit et Sans Envoi

PDFree divise vos fichiers PDF directement dans le navigateur — sans envoi, sans inscription. Extrayez des pages spécifiques ou séparez chaque page en fichier individuel téléchargé dans une archive ZIP. Aucun logiciel à installer, aucune limite de taille.

Diviser un PDF en 3 étapes

Étape 1 — Charger le fichier : Cliquez sur Choisir un fichier ou faites glisser votre PDF dans la zone de dépôt.

Étape 2 — Choisir le mode : Sélectionnez "Toutes les pages" pour créer un PDF par page, ou entrez des plages personnalisées (ex. : 1–3, 5, 8–10) pour extraire des sections spécifiques.

Étape 3 — Diviser et télécharger : Cliquez sur Diviser le PDF. Les fichiers résultants sont regroupés dans une archive ZIP et téléchargés immédiatement.

Modes de division

Toutes les pages : Chaque page du document devient un fichier PDF distinct. Utile pour les formulaires multi-pages ou les documents à distribuer individuellement.

Par plages de pages : Définissez exactement quelles pages extraire. Les plages peuvent être disjointes — par exemple 1–3, 7, 10–12 dans un seul lot.

Cas d'usage courants

Extraire un chapitre : Isolez un chapitre d'un rapport de 200 pages pour le partager séparément sans diffuser l'intégralité du document.

Documents scannés page par page : Si vous avez reçu un scan où chaque page est une pièce jointe séparée, vous pouvez d'abord les fusionner puis les redistribuer page par page.

Préparer des sections pour révision : Envoyez uniquement les pages pertinentes à chaque relecteur sans exposer le document complet.

Formulaires administratifs : Séparez les pages d'un formulaire rempli pour archiver chaque section dans le bon dossier.

Questions fréquentes

Mes fichiers sont-ils envoyés à un serveur ?
Non. PDFree traite tous les fichiers entièrement dans votre navigateur. Vos documents ne quittent jamais votre appareil.
Quelle est la différence entre Diviser et Extraire ?
Diviser décompose tout le document en fichiers séparés (un par page ou par plage). Extraire crée un seul fichier contenant uniquement les pages sélectionnées — plus précis pour les sélections non consécutives.
Le PDF original est-il modifié ?
Non. PDFree crée de nouveaux fichiers à partir de copies des pages. Le fichier original reste intact sur votre appareil.
Y a-t-il des limites de taille ou de nombre de pages ?
Non. PDFree n'a pas de limites artificielles. La seule contrainte est la mémoire vive disponible sur votre appareil.
PDFree fonctionne-t-il hors ligne ?
Oui. PDFree est une Progressive Web App (PWA) et fonctionne entièrement hors ligne après le premier chargement.
