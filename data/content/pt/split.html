Dividir PDF Online — Grátis e Sem Upload

O PDFree divide seus arquivos PDF diretamente no navegador — sem upload, sem cadastro. Extraia páginas específicas ou separe cada página em arquivo individual baixado em um arquivo ZIP. Sem software para instalar, sem limite de tamanho.

Dividir um PDF em 3 passos

Passo 1 — Carregar o arquivo: Clique em Escolher arquivo ou arraste seu PDF para a área de upload.

Passo 2 — Escolher o modo: Selecione "Todas as páginas" para criar um PDF por página, ou insira intervalos personalizados (ex.: 1–3, 5, 8–10) para extrair seções específicas.

Passo 3 — Dividir e baixar: Clique em Dividir PDF. Os arquivos resultantes são agrupados em um ZIP e baixados imediatamente.

Modos de divisão

Todas as páginas: Cada página do documento se torna um arquivo PDF separado. Útil para formulários com múltiplas páginas ou documentos a serem distribuídos individualmente.

Por intervalos de páginas: Defina exatamente quais páginas extrair. Os intervalos podem ser descontínuos — por exemplo 1–3, 7, 10–12 em um único lote.

Casos de uso comuns

Extrair um capítulo: Isole um capítulo de um relatório de 200 páginas para compartilhar separadamente sem distribuir o documento completo.

Preparar seções para revisão: Envie apenas as páginas relevantes para cada revisor sem expor o documento completo.

Formulários administrativos: Separe as páginas de um formulário preenchido para arquivar cada seção na pasta correta.

Documentos digitalizados: Divida um grande scan em páginas individuais para identificar e reorganizar o conteúdo.

Perguntas Frequentes

Meus arquivos são enviados para um servidor?
Não. O PDFree processa todos os arquivos inteiramente no seu navegador. Seus documentos nunca saem do seu dispositivo.
Qual a diferença entre Dividir e Extrair?
Dividir decompõe todo o documento em arquivos separados (um por página ou por intervalo). Extrair cria um único arquivo contendo apenas as páginas selecionadas — mais preciso para seleções não consecutivas.
O PDF original é modificado?
Não. O PDFree cria novos arquivos a partir de cópias das páginas. O arquivo original permanece intacto no seu dispositivo.
Existe um limite de tamanho ou número de páginas?
Não. O PDFree não tem limites artificiais. A única restrição é a memória RAM disponível no seu dispositivo.
O PDFree funciona offline?
Sim. O PDFree é um Progressive Web App (PWA) e funciona completamente offline após o primeiro carregamento.
