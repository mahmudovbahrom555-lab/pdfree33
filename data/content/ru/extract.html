Извлечь страницы PDF онлайн бесплатно — без загрузки на сервер, без регистрации

Нужно извлечь определённые страницы из PDF в отдельный файл? PDFree извлекает выбранные страницы из PDF прямо в браузере — обработка происходит в браузере без загрузки на сервер. Указывайте диапазоны и отдельные страницы. Исходный файл остаётся неизменным. Без регистрации, полностью бесплатно.

Как извлечь страницы PDF за 3 шага

1
Выберите PDF-файл

Нажмите Выбрать файл или перетащите PDF в область загрузки. Файл загружается только в браузер — на сервер ничего не отправляется.

2
Укажите страницы для извлечения

Введите номера страниц или диапазоны: например, «1-3, 5, 7-9» извлечёт страницы 1, 2, 3, 5, 7, 8 и 9 в один новый PDF.

3
Скачайте новый PDF

Нажмите Извлечь страницы. Скачайте новый PDF только с выбранными страницами. Исходный файл остаётся неизменным.

Отправка части документа

Нужно отправить только конкретный раздел из объёмного договора или отчёта? Извлеките нужные страницы вместо отправки всего документа.

Извлеките конкретные приложения или приложения из большого PDF для отдельной передачи контрагенту или в архив.

Быстрый способ удалить страницы — извлечь только нужные и сохранить их в новый файл. Исходный PDF при этом не изменяется.

Извлеките только нужные главы или страницы из PDF-книги или учебника для более удобного использования.

Часто задаваемые вопросы

Загружается ли мой PDF на сервер при извлечении страниц?

Нет. Извлечение выполняется полностью в браузере с помощью JavaScript. Файл не покидает ваше устройство — никакие данные не передаются на сервер.

Хранит ли PDFree или записывает ли мои файлы после обработки?

Нет. PDFree работает полностью в вашем браузере — нет никакого сервера, который получал бы ваши файлы. Поскольку ничего не загружается, ничего не может быть сохранено, записано или удержано. Ваш документ существует только в памяти браузера в течение сессии и удаляется при закрытии вкладки.

Как задать диапазоны страниц для извлечения?

Введите номера через запятую: «1-3, 5, 7-9» создаст новый PDF со страницами 1, 2, 3, 5, 7, 8 и 9. Диапазоны и одиночные страницы можно комбинировать.

Изменяется ли исходный PDF при извлечении страниц?

Нет. PDFree создаёт новый PDF с выбранными страницами. Исходный файл не изменяется — он остаётся у вас в первоначальном виде.

В чём разница между «извлечь страницы» и «разделить PDF»?

«Извлечь страницы» создаёт один PDF с выбранными страницами. «Разделить PDF» может создавать несколько отдельных файлов по диапазонам или по одной странице.

Сохраняются ли гиперссылки в извлечённом PDF?

Да. PDFree сохраняет гиперссылки и внутренние ссылки в извлечённых страницах. Ссылки на страницы, не вошедшие в извлечение, могут стать недействительными.
