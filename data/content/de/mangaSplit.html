Manga-Seiten teilen — Doppelseiten in zwei richtig sortierte Seiten aufteilen

Gescannte Manga-Bände und viele digitale Ausgaben speichern Doppelseiten als ein einziges breites Bild oder eine PDF-Seite. Auf dem Bildschirm ist das kein Problem, aber es stört beim Drucken, auf E-Readern und beim seitenweisen Lesen — der Falz landet mitten in einem Panel. PDFrees Tool „Manga-Seiten teilen" schneidet jede Doppelseite sauber in der Mitte durch, in zwei vollformatige Seiten, standardmäßig in der richtigen Von-rechts-nach-links-Lesereihenfolge, komplett in deinem Browser.

So teilst du Manga-Doppelseiten in 3 Schritten

1
Öffne deine PDF

Klicke auf Dateien auswählen oder ziehe deine PDF in die Ablagezone. Ein Raster mit Miniaturansichten aller Seiten wird in deinem Browser geladen — die Datei wird nie an einen Server gesendet.

2
Prüfe die Lesereihenfolge, markiere Seiten, die ganz bleiben sollen

Die Manga-Lesereihenfolge (rechte Seite zuerst) ist standardmäßig aktiv — schalte sie für Comics oder Manhwa mit Links-nach-rechts-Leserichtung aus. Klicke im Miniaturraster auf ein Cover, eine Titelseite oder eine beliebige Einzelseite, um sie ungeteilt zu lassen.

3
Lade deine geteilte PDF herunter

Aus jeder Doppelseite werden zwei vollständige Seiten in einer neuen PDF, bereit zum seitenweisen Lesen auf einem Gerät oder zum Drucken. Es werden kein Text, keine Seitenzahlen und kein Layout hinzugefügt — das Teilen ist bewusst das Einzige, was dieses Tool macht.

Warum die Teilung vektorbasiert sein muss, nicht wie ein Screenshot

Eine Doppelseite lässt sich teilen, indem man jede Seite als Bild rendert und in der Mitte zuschneidet — aber dabei gehen Textqualität und Linienschärfe des Originals verloren, und die Auflösung des Screenshots wird fest eingebrannt. PDFree schneidet stattdessen den eigentlichen PDF-Seiteninhalt zu, sodass Text dort auswählbar bleibt, wo die Quell-PDF echten Text hatte, und die Bildqualität genau der der Quellseite entspricht — nichts wird dabei neu kodiert oder neu abgetastet.

Wann du das brauchst

Eigene Scans seitenweise auf dem Handy oder E-Reader lesen

Eine breite Doppelseite wird auf einem Handy-Bildschirm zu unlesbar kleinem Text. Nach dem Teilen in zwei Seiten füllt jede Seite den Bildschirm in lesbarer Größe.

Einen gekauften digitalen Band oder eigenes Doujinshi drucken

Heim- und Copyshop-Drucker erwarten Einzelseiten, keine Doppelseiten. Teile die Datei zuerst, dann drucken und binden sich alle Seiten korrekt.

Eigene Scans oder Lehrmaterial als Einzelseiten archivieren

Seitenweise Dateien lassen sich leichter referenzieren, zitieren oder neu ordnen als eine an Doppelseiten gebundene PDF.

Für deine eigenen Inhalte gedacht

Dieses Tool ist zum Teilen von Doppelseiten in Dateien gedacht, die du nutzen darfst — eigene Scans von physischen Büchern, die dir gehören, gekaufte digitale Bände, dein eigenes Doujinshi oder Originalwerk sowie Lehr- oder Archivmaterial. Es lädt keinen Manga herunter, hostet oder verbreitet keinen — es verarbeitet nur eine Datei, die du bereits besitzt, komplett auf deinem eigenen Gerät.

Häufig gestellte Fragen

Lädt das Teilen einer Manga-PDF meine Datei auf einen Server hoch?

Nein. Jede Seite wird komplett in deinem Browser geteilt. Deine Datei wird nirgendwohin gesendet.

In welcher Reihenfolge kommen die geteilten Seiten heraus?

Standardmäßig in der Manga-Lesereihenfolge — zuerst die rechte Hälfte jeder Doppelseite, dann die linke. Schalte den Manga-Umschalter für Inhalte mit Links-nach-rechts-Leserichtung wie westliche Comics oder manche Manhwa aus, dann kommt stattdessen die linke Hälfte zuerst.

Kann ich ein Cover oder eine Einzelseite vom Teilen ausnehmen?

Ja. Klicke im Miniaturraster auf eine beliebige Seite, um sie als „nicht teilen“ zu markieren — nützlich für Cover, Titelseiten oder Einzelseiten, die zwischen lauter Doppelseiten liegen. Sie bleibt in Originalgröße unverändert.

Verschlechtert das Teilen die Bild- oder Textqualität?

Nein. Das Tool schneidet den eigentlichen PDF-Seiteninhalt zu, statt ihn erst als Bild zu rendern, sodass Text dort auswählbar bleibt, wo die Quelle echten Text hatte, und die Bildqualität unverändert bleibt — nichts wird neu kodiert oder neu abgetastet.

Fügt dieses Tool Text, Seitenzahlen oder ein Drucklayout hinzu?

Nein — diese Version teilt nur Doppelseiten in zwei Seiten. Es werden bewusst keine Textüberlagerungen, Seitenzahlen oder Booklet-/Ausschieß-Layouts hinzugefügt.

Kann ich das für Scanlations oder Manga verwenden, die ich woanders heruntergeladen habe?

Dieses Tool ist für Inhalte gedacht, die du nutzen darfst — eigene Scans von Büchern, die dir gehören, gekaufte digitale Bände, dein eigenes Doujinshi oder Originalwerk sowie Lehrmaterial. Es lädt keinen Manga herunter und hostet keinen — es verarbeitet nur eine Datei, die bereits auf deinem Gerät liegt.

Gibt es ein Limit für die Seitenzahl?

Kein Limit für die Seitenzahl und kein Konto nötig. Sehr große gescannte Bände können länger dauern, da alles auf deinem eigenen Gerät läuft.
