Domande Frequenti

Che tipo di crittografia viene usata?

AES-256 — lo stesso standard usato dalle banche e dai servizi governativi. È la crittografia più sicura disponibile per i PDF.

PDFree conserva o registra i miei file dopo l'elaborazione?

No. PDFree funziona interamente nel tuo browser — non esiste alcun server backend che riceva i tuoi file. Poiché nulla viene caricato, nulla può essere conservato, registrato o trattenuto. Il tuo documento esiste solo nella memoria del browser per la durata della sessione e viene eliminato alla chiusura della scheda.

Il file viene caricato su un server?

No. La crittografia avviene interamente nel browser usando JavaScript. Il file non lascia mai il tuo dispositivo.

Posso proteggere PDF di grandi dimensioni?

Sì. Non c'è limite di dimensione. L'elaborazione avviene nella memoria del browser.

Posso rimuovere la password in seguito?

Sì. Usa il nostro strumento Sblocca PDF (coming soon) o un lettore PDF inserendo la password.

È conforme al GDPR?

Sì — i file non lasciano mai il browser. Nessun dato viene inviato a server. Completamente conforme al GDPR.

Perché usare PDFree per proteggere PDF?

PDFree protegge PDF con password gratuitamente — senza account, senza software, senza upload. Crittografa i tuoi documenti all'istante nel tuo browser con AES-256. A differenza degli strumenti cloud tipici, PDFree non ha restrizioni. I tuoi file non lasciano mai il dispositivo.
