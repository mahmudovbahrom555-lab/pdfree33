Domande Frequenti

Quanti file PDF posso unire in una volta?

Nessun limite. PDFree elabora tutto nella memoria del browser — puoi unire 2, 50 o 100+ file in un'unica operazione. Per lotti grandi (50+ file o più di 500 MB), chiudi altre schede per liberare RAM.

La formattazione verrà preservata dopo l'unione?

Sì. PDFree usa pdf-lib che copia le pagine a livello di oggetti PDF — font, immagini, grafica vettoriale e formattazione vengono preservati esattamente come negli originali.

Posso unire PDF protetti da password?

No. I PDF cifrati non possono essere letti senza la password. Rimuovi prima la protezione, poi unisci.

C'è un limite giornaliero per unire PDF?

No. PDFree non ha restrizioni d'uso. Unisci quanti PDF vuoi, con la frequenza che desideri — senza limite giornaliero, senza limite di operazioni, senza limite di file.

I miei file vengono caricati su un server?

No. Tutto viene elaborato nella memoria del tuo browser. Nessun file viene inviato a nessun server. Chiudi la scheda e i file scompaiono completamente dalla memoria.

Funziona su Mac?

Sì. PDFree funziona su tutti i browser moderni — Safari su Mac e iPhone, Chrome su Mac, Windows e Android. Nessuna app da installare.

Perché usare PDFree per unire PDF?

PDFree è un combinatore PDF online gratuito — senza account, senza software, senza upload. Combina PDF illimitati all'istante nel tuo browser. A differenza degli strumenti cloud tipici che limitano dimensione e operazioni giornaliere nel piano gratuito, PDFree non ha restrizioni. I tuoi documenti non lasciano mai il tuo dispositivo.

  • Gratis per sempre — unisci PDF senza abbonamento o limite giornaliero
  • Senza registrazione — trascina i file e unisci subito
  • 100% privato — file combinati localmente nel browser, mai caricati
  • Senza limite di dimensione — unisci PDF di qualsiasi dimensione, anche 100 MB+
  • File illimitati — combina 2, 10, 50 o 100+ PDF con un clic
  • Funziona su mobile — unisci PDF su iPhone (Safari) o Android (Chrome)
