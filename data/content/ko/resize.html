인쇄용 PDF 크기 조정 — 잘리거나 작게 인쇄되는 페이지 문제 해결

PDF를 인쇄하면 가장자리가 잘리거나, 내용이 아래로 밀리거나, 한쪽 구석에 작게 쪼그라들어 나오나요? 대개 프린터 자체의 문제가 아닙니다 — 브라우저나 드라이버의 '페이지에 맞춤' 설정이 잘못 추측하고 있는 것이며, 인쇄할 때마다 결과가 달라지기도 합니다. PDFree의 'PDF 크기 조정' 도구는 이 문제를 근본적으로 해결합니다. 모든 페이지를 A4, Letter, Legal, A3, A5 중 하나에 영구적으로 맞추고 그 결과를 새 파일로 저장하므로, 미리보기에서 본 그대로가 프린터에서 그대로 나옵니다 — 더 이상 인쇄 대화상자의 설정에 기댈 필요가 없습니다.

PDF 크기를 3단계로 조정하는 방법

1
PDF 열기

파일 선택을 클릭하거나 PDF를 드롭 영역으로 드래그하세요. 1페이지의 실시간 미리보기가 브라우저에 바로 로드됩니다 — 파일이 서버로 전송되는 일은 없습니다.

2
용지 크기와 맞춤 모드 선택

A4, Letter, Legal, A3, A5 중 하나를 선택한 다음, 맞추기(페이지 전체가 보임), 채우기(가장자리까지 꽉 채움, 일부 잘릴 수 있음), 원본 크기(배율 조정 없음, 정확한 축척을 유지해야 하는 문서용) 중 하나를 선택합니다. 미리보기가 실시간으로 업데이트되며, 적용하기 전에 정확한 배율(%)을 확인할 수 있습니다.

3
다운로드 후 안심하고 인쇄

PDF 크기 조정을 클릭하세요. 모든 페이지가 지정한 용지 크기로 다시 만들어져 즉시 다운로드됩니다 — 원하는 PDF 리더에서 열어 100% 배율로 인쇄하면 되며, '페이지에 맞춤'의 추측에 의존할 필요가 없습니다.

인쇄 시 '페이지에 맞춤'보다 파일 자체의 크기 조정이 더 나은 이유

프린터 지원 포럼을 검색해 보면 형태만 다를 뿐 같은 불만을 수없이 발견하게 됩니다 — 맨 아래 줄이 빠진 채 인쇄되는 PDF, 한쪽 구석에 쪼그라들어 나오는 보고서, 왼쪽이 잘려 인쇄되는 페이지 등. 흔한 해결책은 인쇄 대화상자의 배율 설정을 바꾸는 것이지만, 이 설정은 브라우저나 PDF 리더 안에 있어 앱이 바뀌면 초기화되고, 사용하는 기기와 프린터 드라이버마다 다르게 동작합니다. PDFree의 크기 조정 도구는 파일 자체를 목표 용지 크기로 영구히 다시 만들어 이 문제를 완전히 피해 갑니다. 수정 결과가 문서 자체에 담기므로, 이후 누가 파일을 열든 상관없습니다. 비슷한 크기 조정 기능을 제공하는 무료 경쟁 서비스들은 대개 제한을 둡니다 — 예를 들어 Sejda의 크기 조정 도구는 무료 요금제에서 시간당 3개 작업, 200페이지 또는 50MB로 제한됩니다. PDFree에는 작업 수 제한도, 페이지 수 제한도, 계정 요구도 전혀 없습니다.

PDF 크기 조정이 필요한 경우

US Letter 크기 PDF를 A4로 인쇄해야 할 때 (또는 그 반대)

한 지역의 기본 용지 크기에 맞춰 만든 문서는 다른 용지 크기에서 인쇄하면 살짝 어긋나거나 잘릴 수 있습니다. 프린터에 실제로 넣은 용지에 맞게 크기를 조정하세요.

계약서와 보고서에 일관되고 전문적인 모습이 필요할 때

여러 출처에서 모은 업무 문서는 페이지 크기가 뒤섞이는 경우가 있습니다. 고객에게 전달할 PDF를 보내거나 인쇄하기 전에 모든 페이지를 같은 용지 크기로 맞추세요.

학교 및 학술 제출물의 서식 요건

과제와 제출물은 특정 용지 크기를 요구하는 경우가 많습니다. 인쇄하거나 업로드하기 전에 문서를 A4 또는 Letter에 맞추세요.

정확한 축척을 유지해야 하는 서식, 패턴, 도면

재봉 패턴, 공식 서식, 축척 도면 같은 일부 문서는 조금이라도 크기가 바뀌면 쓸모없어집니다. 원본 크기 모드를 사용하면 픽셀 하나도 배율을 조정하지 않고 원본 내용을 새 용지 크기 위에 배치할 수 있습니다.

자주 묻는 질문

PDF 크기를 조정하면 파일이 서버에 업로드되나요?

아니요. 모든 페이지는 브라우저에서 완전히 다시 만들어집니다. 파일이 어디로도 전송되지 않습니다.

화면에서는 멀쩡해 보이는데 PDF를 인쇄하면 왜 잘려서 나오나요?

대개 파일 속 페이지 크기와 프린터에 넣은 용지 크기가 일치하지 않기 때문이며, 브라우저나 드라이버의 자동 '페이지에 맞춤' 기능이 그 차이를 메우는 방법을 일관성 없이 추측하고 있는 것입니다. PDF 자체를 원하는 용지 크기로 조정해 두면 이런 추측을 영구히 없앨 수 있습니다.

'맞추기', '채우기', '원본 크기'는 어떻게 다른가요?

맞추기는 페이지 전체가 새 용지 크기에 다 보이도록 축소하며, 비율이 정확히 맞지 않으면 여백이 남습니다. 채우기는 새 페이지를 가장자리까지 꽉 채우도록 확대하므로 양쪽이 조금 잘릴 수 있습니다. 원본 크기는 배율을 전혀 조정하지 않고 원본 내용을 새 용지 크기의 중앙에 실제 크기 그대로 배치합니다. 크기가 바뀌면 안 되는 패턴, 서식, 도면에 적합합니다.

방향의 '자동' 설정은 어떤 기능인가요?

'자동'은 새 페이지의 방향을 원본 페이지 각각의 방향에 맞춥니다 — 가로 페이지는 가로 용지에, 세로 페이지는 세로 용지에 배정되어, 폭이 넓은 스프레드시트 인쇄물이 세로로 긴 틀에 작은 배율로 눌려 들어가지 않습니다. 모든 페이지를 세로 또는 가로로 강제 지정할 수도 있습니다.

크기를 조정할 수 있는 페이지 수에 제한이 있나요?

아니요. 페이지 수나 파일 크기 제한, 시간당 작업 수 제한 모두 없습니다. 2페이지 서식이든 500페이지 보고서든 필요한 만큼 몇 번이고 크기를 조정하세요.

크기를 조정하면 이미지나 텍스트 화질이 떨어지나요?

아니요. 각 페이지는 벡터 객체로 삽입되어 수학적으로 배율이 조정됩니다. 래스터 이미지로 다시 렌더링되는 것이 아니므로 텍스트는 선명하고 검색 가능한 상태를 유지하며, 이미지도 새 배율에 맞는 원본 해상도를 유지합니다.

Letter와 A4 페이지가 섞인 PDF도 크기를 조정할 수 있나요?

네. 각 페이지가 개별적으로 측정되고 맞춰지므로, 원본 페이지 크기가 뒤섞인 문서라도 결과물에서는 하나의 통일된 용지 크기로 합쳐집니다.

여러 PDF 파일을 한 번에 크기 조정할 수 있나요?

크기 조정은 한 번에 하나의 PDF 파일만 처리합니다. 모두 동일한 처리가 필요한 파일이라면 압축, 워터마크 같은 PDFree의 다른 도구가 여러 파일을 한 번에 처리하는 기능을 지원합니다.

휴대폰에서도 PDF 크기를 조정할 수 있나요?

네. PDFree는 모바일 Safari(iOS)와 Android용 Chrome에서 작동합니다 — 동일한 용지 크기와 맞춤 모드 설정을 탭 한 번으로 조작할 수 있습니다.

PDF 크기 조정 도구는 완전히 무료인가요?

네. PDFree는 구독료, 일일·시간당 제한, 가입 없이 무료입니다. 결과물에 워터마크가 추가되지 않으며 파일 크기 제한도 없습니다.

PDF 크기 조정에 PDFree를 사용해야 하는 이유

PDFree는 무료 온라인 PDF 크기 조정 도구입니다 — 가입, 계정, 설치 없이 어떤 PDF든 인쇄용으로 A4, Letter, Legal, A3, A5에 맞출 수 있습니다. 데스크톱 인쇄 대화상자나 서버 기반 서비스와 달리, PDFree는 브라우저 안에서 즉시 PDF를 다시 만듭니다 — 파일이 기기를 벗어나는 일이 없습니다. 시간당·일일 제한도, 워터마크도, 파일 크기 제한도 없습니다. Windows, Mac, Linux, iOS, Android에서 작동합니다.
