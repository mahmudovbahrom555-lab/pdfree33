PDF 분할 — 무료, 업로드 없이

특정 페이지 추출, 섹션 분리, 공유 전 크기 축소 등을 위해 PDF를 나누어야 할 때가 있습니다. PDFree는 브라우저에서 PDF를 분할합니다: 업로드 없음, 회원가입 없이, 제한 없이.

PDF 분할 3단계

1
PDF 업로드

파일 선택을 클릭하거나 PDF를 드래그하세요.

2
페이지 선택

단일 페이지, 범위(예: 1-3, 5, 7-9) 또는 모든 페이지를 개별 파일로 선택하세요.

3
분할 및 다운로드

PDF 분할을 클릭하세요. 추출된 페이지를 개별 파일 또는 단일 PDF로 다운로드하세요.

PDF 분할이 유용한 경우

챕터 추출

긴 보고서나 매뉴얼을 개별적으로 공유할 수 있도록 챕터별로 분리하세요.

불필요한 페이지 제거

공유 전 표지, 워터마크, 빈 페이지를 제거하세요.

크기 줄이기

문서를 이메일에 첨부하기 전에 관련 페이지만 추출하세요.

복수 문서 분리

여러 문서가 하나의 PDF로 스캔된 경우, 각 문서를 개별적으로 분리하세요.

100% 비공개 — 파일이 기기를 절대 벗어나지 않습니다

PDFree는 브라우저 안에서만 PDF를 분할합니다. 어떤 파일도 서버로 업로드되지 않습니다 — PDFree 서버는 물론 제3자 서버로도 전송되지 않습니다. 브라우저가 PDF를 로컬에서 읽고, 선택한 페이지를 추출해, 결과 파일을 기기에 직접 저장합니다.

이는 재무 보고서, 계약서, 의료 기록, 법률 문서 등 기밀 문서에서 중요합니다. 내용이 내 컴퓨터에만 남는다는 확신을 가지고 페이지를 분할하고 추출할 수 있습니다.

자주 묻는 질문

특정 페이지를 추출할 수 있나요?

예. 단일 페이지, '1-3, 5, 7-9'와 같은 범위, 또는 모든 페이지를 개별 파일로 선택할 수 있습니다.

PDFree는 처리 후 내 파일을 저장하거나 기록하나요?

아니요. PDFree는 완전히 브라우저에서 실행됩니다 — 파일을 받는 백엔드 서버가 없습니다. 업로드되는 것이 없으므로 저장, 기록 또는 보관될 수 없습니다. 문서는 세션 동안만 브라우저 메모리에 존재하며 탭을 닫으면 삭제됩니다.

파일이 서버로 업로드되나요?

아니요. 모든 작업이 브라우저에서 이루어집니다. 파일은 기기를 떠나지 않습니다.

대용량 PDF도 분할할 수 있나요?

예. PDFree는 브라우저에서 대용량 PDF를 처리합니다. 매우 큰 파일(500MB 이상)의 경우 충분한 RAM이 있는지 확인하세요.

하루 사용 횟수 제한이 있나요?

아니요. PDFree는 사용 제한이 없습니다. 원하는 만큼 PDF를 분할하세요.

추출된 페이지가 원본 품질을 유지하나요?

예. PDFree는 PDF 객체 수준에서 페이지를 추출합니다 — 품질, 글꼴, 이미지가 원본과 동일하게 유지됩니다.

모든 페이지 분할: 얻게 되는 결과

"모든 페이지 분할"을 선택하면 PDFree가 각 페이지를 개별 1페이지 PDF로 변환합니다. 브라우저는 수십 개의 개별 파일을 한 번에 다운로드할 수 없으므로, page-001.pdf, page-002.pdf 등의 이름으로 하나의 ZIP 파일로 묶입니다 — 앞자리 0 덕분에 99페이지를 넘어도 모든 파일 관리자에서 올바른 순서로 정렬됩니다. 페이지 수 제한은 없습니다: 500페이지 PDF는 500개의 개별 파일이 담긴 ZIP을 만들며, 제한은 기기의 CPU 성능뿐입니다.

워터마크 없음, 항상

분할된 페이지는 원본 PDF와 완전히 동일한 내용입니다 — 로고 없음, "Created with PDFree" 스탬프 없음, 광고 표시 없음. 많은 무료 온라인 분할 도구는 유료 플랜으로 유도하기 위해 워터마크를 추가하지만, PDFree는 업그레이드할 유료 플랜 자체가 없기 때문에 그렇게 하지 않습니다.
