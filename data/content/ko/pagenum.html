PDF에 페이지 번호 추가 — 무료, 업로드 없음

PDFree는 브라우저에서 바로 PDF에 페이지 번호를 추가합니다 — 서버 업로드 없음, 가입 불필요. 위치, 형식(아라비아, 로마, 알파벳), 시작 번호, 접두사/접미사를 자유롭게 설정할 수 있습니다.

3단계로 페이지 번호 추가하기

1단계 — 파일 업로드: 파일 선택을 클릭하거나 PDF를 업로드 영역으로 드래그하세요.

2단계 — 형식 설정: 위치(위/아래, 왼쪽/가운데/오른쪽), 번호 형식, 시작 페이지 번호를 선택하세요. 선택 사항으로 접두사(예: "페이지 ") 또는 접미사(예: " / 10")를 추가할 수 있습니다.

3단계 — 다운로드: 페이지 번호 추가를 클릭하세요. 번호가 매겨진 PDF가 자동으로 다운로드됩니다.

사용자 지정 옵션

위치: 왼쪽 위, 가운데 위, 오른쪽 위 — 또는 같은 위치의 아래쪽. 총 6가지 위치를 사용할 수 있습니다.

형식: 아라비아 숫자(1, 2, 3), 로마 숫자(I, II, III) 또는 알파벳(A, B, C).

시작 번호: 자유롭게 설정 가능 — 표지나 목차를 건너뛸 수 있습니다.

접두사/접미사: "페이지 1 / 10", "- 1 -" 또는 원하는 형식.

일반적인 사용 사례

보고서 및 발표자료: 페이지 번호는 독자가 전문 문서에서 방향을 잡는 데 도움이 됩니다.

법률 문서: 계약서와 법원 문서는 참조를 위해 정확한 페이지 번호를 요구하는 경우가 많습니다.

병합된 PDF: 여러 파일을 병합한 후 연속된 페이지 번호를 추가하세요.

학위 논문: 논문은 정확한 페이지 번호가 필요하며, 표지와 목차는 종종 제외됩니다.

여러 PDF 파일에 한 번에 페이지 번호 추가하기

여러 보고서나 챕터에 번호를 매기고 있나요? 여러 PDF 파일을 선택하거나 끌어다 놓으면 PDFree가 선택한 형식과 위치로 각 파일의 페이지에 번호를 매깁니다, 브라우저에서 바로. 번호가 매겨진 파일들은 다운로드할 수 있는 하나의 ZIP으로 묶입니다.

자주 묻는 질문

1이 아닌 다른 번호부터 시작할 수 있나요?
네. "시작 번호" 필드에 원하는 시작 번호를 입력하세요. 표지를 0페이지로 취급하는 문서에 유용합니다.
PDFree는 처리 후 내 파일을 저장하거나 기록하나요?
아니요. PDFree는 완전히 브라우저에서 실행됩니다 — 파일을 받는 백엔드 서버가 없습니다. 업로드되는 것이 없으므로 저장, 기록 또는 보관될 수 없습니다. 문서는 세션 동안만 브라우저 메모리에 존재하며 탭을 닫으면 삭제됩니다.
어떤 번호 형식을 사용할 수 있나요?
아라비아 숫자(1, 2, 3), 소문자 로마 숫자(i, ii, iii), 대문자 로마 숫자(I, II, III), 소문자 및 대문자 알파벳.
"페이지 1 / 20" 형식을 추가할 수 있나요?
네. 번호 앞에 텍스트를 넣으려면 접두사 필드(예: "페이지 ")를, 뒤에 넣으려면 접미사 필드(예: " / 20")를 사용하세요.
페이지 번호가 표시될 위치를 선택할 수 있나요?
네. 위치 옵션: 아래 가운데, 아래 왼쪽, 아래 오른쪽, 위 가운데, 위 왼쪽, 위 오른쪽.
표지를 번호 매기기에서 제외할 수 있나요?
네. 시작 번호를 0으로 설정하거나 2페이지부터 번호를 시작하면 됩니다. 표지에는 번호가 표시되지 않습니다.
제 파일이 서버에 업로드되나요?
아니요. 모든 처리는 사용자의 브라우저에서만 이루어집니다. 문서가 기기를 벗어나는 일은 절대 없습니다.
추가한 후 페이지 번호를 제거할 수 있나요?
아니요. 페이지 번호는 영구적으로 삽입됩니다. 나중에 번호 없는 버전이 필요하다면 원본 파일을 별도로 보관하세요.
페이지 수에 제한이 있나요?
아니요. PDFree에는 인위적인 제한이 없습니다. 유일한 제한은 기기에서 사용 가능한 메모리입니다.
여러 PDF 파일에 한 번에 페이지 번호를 추가할 수 있나요?
네. 여러 PDF 파일을 선택하거나 끌어다 놓으면 PDFree가 선택한 형식으로 각 파일의 페이지에 번호를 매깁니다, 브라우저에서 바로. 번호가 매겨진 파일들은 다운로드할 수 있는 하나의 ZIP으로 묶입니다. 업로드도, 일일 제한도 없습니다.

페이지 번호에 PDFree를 선택하는 이유

PDFree는 무료 온라인 PDF 페이지 번호 매기기 도구입니다 — 계정 불필요, 업로드 없음, 즉시 처리. 위치, 형식, 시작 번호를 완전히 제어하며 브라우저에서 바로 페이지 번호를 추가하세요.

  • 무료 — 구독 없이 페이지 번호 추가

  • 유연한 위치 지정 — 위 또는 아래, 왼쪽, 가운데, 오른쪽
