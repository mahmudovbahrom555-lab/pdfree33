PDF 메타데이터 온라인 편집 — 작성자 삭제, 제목 수정

모든 PDF에는 숨겨진 메타데이터가 있습니다 — 작성자 이름, 만드는 데 사용한 소프트웨어, 생성 날짜, 때로는 회사명까지. PDFree를 사용하면 파일을 업로드하지 않고 비공개로 이 모든 것을 보고 편집할 수 있습니다.

3단계로 PDF 메타데이터 편집하는 방법

1
PDF 업로드

파일 선택을 클릭하거나 PDF를 업로드 영역으로 드래그하세요. 현재 메타데이터 필드가 즉시 읽혀 표시됩니다.

2
필드 편집 또는 삭제

제목, 작성자, 주제, 키워드, 작성 프로그램 필드를 업데이트하세요. 필드를 완전히 제거하려면 텍스트를 지우세요 — 출력 PDF에서 생략됩니다.

3
저장하고 다운로드

메타데이터 저장을 클릭하세요. 새 메타데이터가 포함된 업데이트된 PDF가 다운로드됩니다. 파일 내용(페이지, 이미지, 텍스트)은 변경되지 않습니다.

PDF 메타데이터 편집이 필요한 경우

외부 공유 전 작성자 이름 삭제

업무용 컴퓨터에서 만든 PDF에는 전체 이름과 회사명이 포함되어 있을 수 있습니다. 외부 당사자에게 보내거나 공개하기 전에 작성자 필드를 지우세요.

문서 속성의 잘못된 제목 수정

Word나 Excel에서 내보낸 보고서는 메타데이터에 잘못된 제목이 있는 경우가 많습니다. PDF 리더의 제목 표시줄과 검색 색인에 올바른 제목이 나타나도록 수정하세요.

기밀 문서에서 생성 날짜 삭제

메타데이터의 생성 날짜는 문서가 언제 작성되었는지 드러낼 수 있습니다. 생성 시점이 민감한 정보인 문서를 제출하기 전에 삭제하세요.

게시 전 문서 익명화

학술 논문, 정부 문서, 익명 심사에 제출하는 보고서는 메타데이터에 작성자 이름이나 소속 기관이 포함되어서는 안 됩니다.

자주 묻는 질문

메타데이터를 편집할 때 제 파일이 업로드되나요?

아니요. 메타데이터 편집은 pdf-lib를 사용하여 브라우저에서 완전히 처리됩니다. 파일은 기기를 벗어나지 않습니다.

PDFree가 처리 후 제 파일을 저장하거나 기록하나요?

아니요. PDFree는 완전히 브라우저에서 실행되며 파일을 받는 백엔드 서버가 없습니다. 아무것도 업로드되지 않으므로 아무것도 저장되거나 기록될 수 없습니다. 문서는 세션 동안만 브라우저 메모리에 존재하며 탭을 닫으면 지워집니다.

PDFree는 어떤 메타데이터 필드를 표시하고 편집하나요?

PDFree는 표준 PDF 문서 정보 딕셔너리를 읽고 씁니다: 제목, 작성자, 주제, 키워드, 작성 프로그램(PDF를 만든 애플리케이션), 생성기(사용된 PDF 라이브러리). 수정 날짜는 저장 시 자동으로 업데이트됩니다.

메타데이터 편집이 PDF 내용이나 모양을 바꾸나요?

아니요. 메타데이터는 페이지 내용과 별도로 저장됩니다. 메타데이터 필드를 편집하거나 지우는 것은 텍스트, 이미지, 레이아웃 또는 문서의 보이는 요소에 전혀 영향을 주지 않습니다.

현재 제 PDF에 있는 모든 메타데이터를 볼 수 있나요?

네. PDF를 업로드하면 PDFree가 기존 메타데이터 값을 모두 읽어 양식 필드에 표시합니다. 빈 필드는 해당 데이터가 파일에 없다는 뜻입니다.

메타데이터를 삭제하면 파일 크기가 줄어드나요?

약간 줄어듭니다 — 메타데이터는 PDF 구조의 작은 부분입니다. 대부분의 파일에서 크기 감소는 미미하지만 몇 킬로바이트 정도일 수 있습니다.

PDFree가 편집할 수 없는 메타데이터가 있나요?

네. 일부 Adobe 제품이 삽입하는 XMP 메타데이터 패킷(확장 메타데이터)과 애플리케이션별 사용자 지정 메타데이터는 편집할 수 없을 수 있습니다. PDFree는 가장 일반적인 필드를 다루는 표준 PDF 정보 딕셔너리를 편집합니다.

PDF 메타데이터 편집에 PDFree를 사용해야 하는 이유

PDFree는 무료 온라인 PDF 메타데이터 편집기입니다 — 가입 불필요, 소프트웨어 설치 불필요, 서버로 파일 업로드 없음. 작성자, 제목, 주제, 키워드, 날짜를 브라우저에서 즉시 편집하세요. 문서는 100% 비공개로 유지됩니다. Windows, Mac, iOS, Android에서 작동합니다.
