Convertir PDF a Markdown — Encabezados, Listas y Texto Sin Subir

PDFree convierte el texto de tu PDF en Markdown limpio, detectando encabezados, listas con viñetas y texto en negrita. Todo ocurre en tu navegador, sin subir nada, sin registro. El resultado es un archivo .md listo para usar en cualquier editor, GitHub o CMS.

Convierte PDF a Markdown en 3 pasos

Paso 1 — Cargar archivo: Haz clic en Seleccionar archivo o arrastra el PDF al área de soltar.

Paso 2 — Análisis automático: PDFree detecta encabezados según el tamaño de fuente y listas mediante marcadores típicos (•, ◦, 1., 2., etc.).

Paso 3 — Descargar: Haz clic en Convertir PDF a Markdown. El archivo .md se descarga directamente en tu dispositivo.

Cuándo usar PDF a Markdown

Extraer documentación técnica: Los manuales técnicos y especificaciones en PDF se pueden convertir a Markdown para insertarlos directamente en wikis, repositorios de GitHub o sitios de documentación como MkDocs o Docusaurus.

Reutilizar contenido de blog: Textos antiguos que solo existen en PDF pueden reciclarse como archivo Markdown e importarse en generadores de sitios estáticos como Jekyll o Hugo.

Organizar notas: Los apuntes en PDF o materiales de seminarios se pueden importar como Markdown a Obsidian, Notion o Joplin para continuar trabajando con ellos.

Alimentar CMS: Muchos gestores de contenido como WordPress, Ghost o Contentful soportan Markdown. Convierte el contenido PDF directamente en lugar de transcribirlo a mano.

Preguntas frecuentes

¿Se sube mi PDF a algún servidor?

No. El texto se lee y se estructura en Markdown completamente en tu navegador usando pdf.js. Tu PDF nunca sale de tu dispositivo.

¿Se convierten tablas e imágenes?

No — esta herramienta se centra en texto, encabezados y listas. Las tablas no se convierten a sintaxis Markdown; las imágenes no se incrustan. Para tablas, usa PDF a Excel; para documentos completos con imágenes, usa PDF a Word.

¿Cómo se detectan los encabezados?

PDFree compara el tamaño de fuente de cada línea con el tamaño típico del cuerpo del documento. El texto notablemente más grande se convierte en un encabezado Markdown (#, ## o ### según cuánto más grande sea).

¿Qué tipos de listas se reconocen?

Las líneas con viñetas (•, ◦, ▪ y marcadores similares) y las líneas numeradas (1., 2.) se convierten a sintaxis de lista Markdown. Las listas con letras o números romanos (a., iv.) se dejan como texto normal.

¿Funciona con PDFs escaneados?

Solo si el PDF ya tiene una capa de texto. Los PDFs escaneados basados solo en imágenes no tienen texto extraíble — aplica primero OCR y luego convierte el resultado.
