Cara Memisahkan PDF dalam 3 Langkah

1
Buka PDF Anda

Klik Pilih file atau seret PDF Anda ke area drop. Thumbnail halaman dirender di browser Anda — tidak ada yang diunggah ke server mana pun.

2
Pilih halaman yang ingin diekstrak

Klik halaman yang ingin Anda simpan, atau masukkan rentang seperti 1-5, 8, 11-15. Gunakan tombol pilih cepat untuk mengambil halaman ganjil, genap, atau setengah dokumen.

3
Pisah dan unduh

Klik Pisah PDF. Pilih untuk mendapatkan satu PDF gabungan dari halaman yang dipilih, atau setiap halaman sebagai file terpisah dalam arsip ZIP.

Kapan Perlu Memisahkan PDF

Ekstrak halaman tertentu dari laporan

Laporan tahunan 60 halaman, tetapi Anda hanya butuh tabel keuangan di halaman 22–31. Pisahkan untuk mengekstrak hanya halaman tersebut untuk dibagikan ke akuntan Anda.

Pisahkan scan multi-faktur

Satu scan mengandung 12 faktur berbeda. Pisahkan setiap halaman faktur menjadi PDF sendiri untuk diunggah ke sistem akuntansi Anda.

Hapus halaman pertama atau terakhir

Banyak ekspor PDF menambahkan halaman sampul atau halaman kosong di akhir. Pisahkan untuk mengecualikan halaman tersebut dan hanya menyimpan konten aktual.

Akademik — ekstrak satu bab

Buku teks yang dibagikan sebagai PDF tunggal dapat dipecah bab per bab untuk membaca atau mencetak yang terfokus tanpa mencetak seluruh buku.

Hapus halaman tertentu dari PDF

Perlu menghapus halaman kosong, halaman sampul, atau lampiran rahasia? Pilih semua halaman kecuali yang ingin dihapus, lalu ekstrak. Hasilnya adalah PDF Anda tanpa halaman tersebut — kualitas asli dipertahankan.

100% Pribadi — File Anda Tidak Pernah Meninggalkan Perangkat

PDFree memisahkan PDF sepenuhnya di dalam browser Anda. Tidak ada file yang diunggah ke server mana pun — bukan server PDFree, bukan pihak ketiga mana pun. Browser Anda membaca PDF secara lokal, mengekstrak halaman yang dipilih, dan menulis file hasil langsung ke perangkat Anda.

Ini penting untuk dokumen rahasia: laporan keuangan, kontrak, rekam medis, berkas hukum. Anda dapat memisahkan dan mengekstrak halaman dengan yakin bahwa kontennya tetap di perangkat Anda.

Pertanyaan yang Sering Diajukan

Format rentang halaman apa yang diterima PDFree?

Masukkan halaman dan rentang yang dipisahkan koma: misalnya 1, 3-7, 12, 15-20. Spasi bersifat opsional. Anda juga dapat mengklik thumbnail halaman individual untuk memilih atau membatalkan pilihan secara visual.

Apakah file saya diunggah saat memisahkan PDF?

Tidak. PDFree memisahkan PDF sepenuhnya di browser Anda menggunakan JavaScript. File tidak pernah meninggalkan perangkat Anda.

Apakah PDFree menyimpan atau mencatat file saya setelah diproses?

Tidak. PDFree berjalan sepenuhnya di browser Anda — tidak ada server backend yang menerima file Anda. Karena tidak ada yang diunggah, tidak ada yang bisa disimpan, dicatat, atau dipertahankan. Dokumen Anda hanya ada di memori browser selama sesi berlangsung dan dihapus saat Anda menutup tab.

Bagaimana cara menghapus halaman tertentu dari PDF?

Pilih semua halaman kecuali yang ingin Anda hapus, kemudian klik Pisah PDF untuk mengekstrak hanya halaman yang ingin Anda simpan. Misalnya, untuk menghapus halaman 3 dari PDF 10 halaman, pilih halaman 1-2 dan 4-10 lalu ekstrak.

Bisakah memisahkan PDF secara offline?

Ya. PDFree adalah Progressive Web App dan berfungsi sepenuhnya offline setelah dimuat di browser Anda. Tidak diperlukan koneksi internet untuk memisahkan atau mengekstrak halaman.

Bisakah memisahkan beberapa file PDF sekaligus?

Tidak dalam satu batch — PDFree memproses satu PDF pada satu waktu. Buka alat di tab baru untuk memisahkan file kedua secara paralel.

Bisakah memisahkan PDF menjadi halaman individual?

Ya. Gunakan opsi 'Pisah semua halaman' untuk mendapatkan setiap halaman sebagai file PDF sendiri. Mereka diunduh sebagai arsip ZIP yang diberi nama dengan nomor halamannya.

Apakah pemisahan memengaruhi kualitas PDF?

Tidak. Halaman disalin pada tingkat objek PDF — gambar, font, dan grafik vektor dipertahankan secara identik. Pemisahan tidak merender ulang atau mengompresi ulang apa pun.

Apakah ada batasan ukuran PDF atau jumlah halaman?

Tidak ada batasan sisi server. Batasan praktis adalah memori yang tersedia di browser Anda. PDF dengan ratusan halaman dan gambar resolusi tinggi mungkin memerlukan beberapa detik untuk merender thumbnail.

Bisakah memisahkan PDF yang dilindungi kata sandi?

Ya, jika Anda tahu kata sandinya. Saat Anda membuka PDF yang dilindungi, PDFree akan meminta Anda memasukkannya. Setelah dibuka, Anda dapat memilih dan mengekstrak halaman seperti biasa.

Bisakah memisahkan PDF di iPhone atau Android tanpa Adobe?

Buka PDFree di Safari (iPhone/iPad) atau browser apa pun di Android — tidak diperlukan unduhan aplikasi atau Adobe Acrobat. Alat ini berjalan sepenuhnya di browser: muat PDF, pilih halaman, ketuk Pisah PDF.

Memisahkan Setiap Halaman: Apa yang Anda Dapatkan

Pilih "Pisah semua halaman" dan PDFree mengubah setiap halaman menjadi PDF satu halaman sendiri. Karena browser tidak bisa mengunduh puluhan file terpisah sekaligus, semuanya dikemas dalam satu arsip ZIP, diberi nama page-001.pdf, page-002.pdf, dan seterusnya — angka nol di depan menjaga urutan file tetap benar di manajer file mana pun, bahkan setelah halaman 99. Tidak ada batas halaman: PDF 500 halaman menghasilkan ZIP dengan 500 file individual, hanya dibatasi oleh CPU perangkat Anda.

Tanpa Tanda Air, Selamanya

Halaman hasil pemisahan adalah konten asli dari PDF Anda — tanpa logo, tanpa stempel "Dibuat dengan PDFree", tanpa tanda iklan. Banyak alat pemisah gratis online menambahkan tanda air untuk mendorong Anda ke paket berbayar; PDFree tidak, karena tidak ada paket berbayar untuk ditingkatkan.
