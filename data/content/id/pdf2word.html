Pilih mode Teks (ekstrak teks yang bisa diedit) atau mode Gambar (pertahankan tata letak visual). Mendukung tabel, judul, dan pemformatan dasar. Gratis selamanya, tanpa daftar.

Cara Mengonversi PDF ke Word dalam 3 Langkah

1
Buka file PDF Anda

Klik Pilih file atau seret PDF ke area drop. File dimuat di browser — tidak ada yang diunggah ke server.

2
Pilih mode konversi

Pilih Mode Teks untuk dokumen Word yang dapat diedit dengan paragraf, judul, tabel yang dipertahankan. Pilih Mode Gambar untuk tata letak visual sempurna di mana setiap halaman menjadi gambar di Word.

3
Konversi dan unduh

Klik Konversi ke Word. File DOCX diunduh langsung ke perangkat Anda. Buka di Microsoft Word, Google Docs, LibreOffice, atau Apple Pages.

Mode Teks vs. Mode Gambar — Mana yang Harus Dipilih

📝 Mode Teks
  • Teks sepenuhnya dapat diedit di Word
  • Judul terdeteksi berdasarkan ukuran font
  • Tebal, miring, ukuran font dipertahankan
  • Tabel diekstrak sebagai tabel Word
  • Berfungsi untuk Latin, Sirilik, Arab, Ibrani, CJK
  • Terbaik untuk: kontrak, laporan, artikel
🖼️ Mode Gambar
  • Tata letak dipertahankan piksel demi piksel
  • Pilih DPI: 72 / 150 / 300
  • Teks tidak dapat diedit di Word
  • Berfungsi untuk PDF apa pun, termasuk hasil pindaian
  • Terbaik untuk: tata letak kompleks, grafik, formulir

Mengonversi PDF Hasil Pindaian ke Word

PDF hasil pindaian adalah foto dokumen — terlihat seperti teks, tetapi kontennya tersimpan sebagai piksel, bukan karakter. Seberapa baik hasilnya tergantung apakah PDF sudah memiliki lapisan teks:

✅
Dipindai dengan lapisan OCR — banyak pemindai dan aplikasi modern (Adobe Scan, Microsoft Lens) menambahkan lapisan teks tersembunyi. Mode Teks mengekstraknya dengan benar meskipun PDF terlihat seperti gambar.
🖼️
Hasil pindaian gambar saja (tanpa lapisan teks) — gunakan Mode Gambar untuk mendapatkan dokumen Word di mana setiap halaman muncul sebagai gambar beresolusi tinggi. Tata letak dipertahankan, tetapi teks tidak bisa diedit.
🔍
Butuh teks yang bisa diedit dari hasil pindaian? — gunakan software OCR terlebih dahulu untuk menambahkan lapisan teks yang bisa dicari, lalu konversi ke Word. Dua langkah, sepenuhnya privat, tanpa upload.

Apa perbedaan Mode Teks dan Mode Gambar?

Mode Teks mengekstrak teks dari PDF dan membuat dokumen Word yang dapat diedit dengan paragraf, judul, tebal, miring, dan tabel. Mode Gambar merender setiap halaman sebagai gambar beresolusi tinggi dan menempatkannya di dokumen Word — tata letak visual dipertahankan persis tetapi teks tidak bisa diedit.

Apakah pemformatan akan terlihat sama di Word?

Dalam mode teks, konten teks dan pemformatan dasar (tebal, miring, ukuran font, judul, tabel) dipertahankan. Tata letak multi-kolom yang kompleks mungkin tidak sepenuhnya cocok. Untuk ketepatan tata letak sempurna, gunakan mode gambar.

Tidak. Format .docx didukung oleh Microsoft Word, Google Docs (unggah ke Drive dan buka), LibreOffice Writer (gratis, sumber terbuka), dan Apple Pages. Anda tidak perlu langganan Microsoft 365 berbayar untuk membuka file.

Apakah berfungsi secara offline?

Ya. Setelah halaman dimuat, PDFree berfungsi sepenuhnya secara offline sebagai Progressive Web App. Tidak diperlukan koneksi internet untuk konversi.
