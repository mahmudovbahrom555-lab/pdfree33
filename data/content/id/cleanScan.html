Cara membersihkan PDF hasil scan dalam 3 langkah

Klik Pilih file atau seret PDF Anda ke zona unggah. Pratinjau sebelum/sesudah langsung dimuat secara instan di browser Anda — file tidak pernah dikirim ke server mana pun.

3
Unduh PDF bersih Anda

Klik Bersihkan & Unduh. Setiap halaman diproses dan dibangun ulang pada kualitas pilihan Anda, siap diunduh secara instan — tanpa menunggu, tanpa email, tanpa akun.

Pertanyaan yang sering diajukan

Apakah membersihkan scan mengunggah file saya ke server?

Tidak. Setiap halaman dianalisis dan dibangun ulang sepenuhnya di browser Anda. File Anda tidak pernah dikirim ke mana pun.

Apa perbedaan antara mode Bersihkan dan Tingkatkan?

Bersihkan meratakan latar belakang menjadi putih murni dan menggelapkan teks untuk kontras maksimal — terbaik untuk halaman teks polos. Tingkatkan mencerahkan halaman dan meningkatkan kontras tanpa memutihkan latar belakang sepenuhnya, sehingga stempel, tanda tangan, dan foto pada halaman tetap dapat dikenali.

Apakah ini akan menghapus foto berwarna atau stempel dari dokumen saya?

Mode Bersihkan dapat memudarkan atau menghapus konten berwarna, karena dirancang untuk mendorong semuanya menjadi teks hitam di atas latar belakang putih. Jika suatu halaman berisi warna yang ingin Anda pertahankan, gunakan mode Tingkatkan — alat ini secara otomatis memperingatkan Anda saat mendeteksi warna pada halaman yang sedang Anda pratinjau.

Mengapa scan saya memiliki bayangan atau gradasi abu-abu?

Scanner flatbed dan kamera ponsel jarang menerangi halaman secara sempurna merata — tulang punggung buku menimbulkan bayangan dekat lipatan, cahaya sekitar berkurang menuju tepi, dan kertas lama memantulkan cahaya secara tidak merata. Ketidakmerataan itu terekam sebagai bagian dari gambar itu sendiri, yang justru diperbaiki oleh analisis latar belakang Bersihkan Scan.

Apakah ada batas berapa banyak halaman yang bisa saya bersihkan?

Tidak. Tidak ada batas jumlah halaman atau ukuran file, dan tidak ada batas tugas per jam. Bersihkan scan satu halaman atau dokumen seratus halaman sesering yang Anda butuhkan.

Apakah pembersihan mengurangi kualitas gambar?

Mode Bersihkan menyimpan halaman sebagai PNG, yang menghindari artefak kompresi yang akan mengaburkan teks hitam-putih yang tajam. Mode Tingkatkan menyimpan sebagai JPEG berkualitas tinggi, sesuai untuk halaman yang masih berisi foto atau konten bertona kontinu.
