Cara Mengekstrak Halaman PDF dalam 3 Langkah

1
Buka file PDF Anda

Klik Pilih file atau seret PDF ke area drop. Halaman akan ditampilkan sebagai thumbnail yang dapat diklik.

2
Pilih halaman yang ingin diekstrak

Klik thumbnail halaman untuk memilihnya, atau masukkan nomor halaman dan rentang (misalnya: 1, 3–5, 8) di kolom input.

3
Ekstrak dan unduh

Klik Ekstrak Halaman. PDF baru yang berisi hanya halaman yang dipilih langsung diunduh ke perangkat Anda.

Pertanyaan yang Sering Diajukan

Apakah ekstrak halaman PDF mengupload file ke server?

Tidak. Semua pemrosesan terjadi di browser menggunakan pdf-lib. File tidak pernah dikirim ke server mana pun.

Bisakah memilih halaman tidak berurutan?

Ya. Pilih halaman individual (misalnya: 1, 3, 7) atau kombinasi rentang dan halaman tunggal (misalnya: 1–3, 5, 8–10) dalam satu operasi.

Apakah ada batasan jumlah halaman yang bisa diekstrak?

Tidak ada. Ekstrak halaman berapa pun dari PDF berapa pun — gratis tanpa batasan.

Apa perbedaan antara ekstrak dan pisah PDF?

Ekstrak menghasilkan satu PDF baru berisi halaman yang dipilih. Pisah PDF biasanya menghasilkan beberapa file terpisah — satu per halaman atau satu per grup.

Apakah font dan gambar dipertahankan saat mengekstrak?

Ya. PDFree menggunakan pdf-lib yang menyalin halaman di tingkat objek PDF — semua font, gambar, dan format dipertahankan persis seperti aslinya.

Bisakah mengekstrak dari PDF yang dilindungi kata sandi?

Tidak. PDF terenkripsi harus dibuka kunci terlebih dahulu sebelum halaman dapat diekstrak.
