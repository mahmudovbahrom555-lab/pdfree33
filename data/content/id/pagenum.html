Cara Menambah Nomor Halaman PDF dalam 3 Langkah

1
Buka file PDF Anda

Klik Pilih file atau seret PDF ke area drop. File dimuat di browser — tidak ada yang diunggah ke server.

2
Atur penomoran

Pilih format (1, 2, 3 / i, ii, iii / A, B, C), posisi (bawah tengah, bawah kanan, atas tengah, dll.), angka awal, dan opsional lewati halaman pertama (untuk halaman sampul).

3
Terapkan dan unduh

Klik Tambah Nomor Halaman. Nomor disematkan sebagai teks bersih di setiap halaman. PDF langsung diunduh.

Pertanyaan yang Sering Diajukan

Apakah file saya diunggah saat menambah nomor halaman?

Tidak. Penomoran halaman diproses sepenuhnya di browser menggunakan JavaScript. File tidak pernah meninggalkan perangkat.

Apakah PDFree menyimpan atau mencatat file saya setelah diproses?

Tidak. PDFree berjalan sepenuhnya di browser Anda — tidak ada server backend yang menerima file Anda. Karena tidak ada yang diunggah, tidak ada yang bisa disimpan, dicatat, atau dipertahankan. Dokumen Anda hanya ada di memori browser selama sesi berlangsung dan dihapus saat Anda menutup tab.

Bisakah saya memulai penomoran dari angka selain 1?

Ya. Atur angka awal di kolom 'Mulai dari'. Berguna untuk dokumen di mana halaman sampul adalah halaman 0, atau untuk bab yang melanjutkan penomoran dari bagian sebelumnya.

Bisakah saya melewati halaman pertama (halaman sampul)?

Ya. Aktifkan opsi 'Lewati halaman pertama'. Halaman 1 (sampul) tidak mendapat nomor, dan penomoran dimulai dari halaman kedua.

Format nomor apa saja yang tersedia?

Angka Arab (1, 2, 3), angka Romawi kecil (i, ii, iii), angka Romawi besar (I, II, III), alfabet kecil (a, b, c), dan alfabet besar (A, B, C).

Apakah menambah nomor halaman mengubah konten yang ada?

Tidak. Nomor halaman ditambahkan sebagai lapisan teks baru di atas konten yang ada. Teks asli, gambar, dan tata letak di bawahnya tidak berubah.

Bisakah saya memilih posisi nomor halaman?

Ya. Pilihan posisi meliputi: bawah tengah, bawah kiri, bawah kanan, atas tengah, atas kiri, dan atas kanan.

Bisakah saya menambahkan format "Halaman 1 dari 20"?

Ya. Gunakan kolom awalan untuk menambahkan teks sebelum angka (mis. "Halaman ") dan kolom akhiran untuk menambahkan teks setelah angka (mis. " dari 20"). Ini membuat format "Halaman 1 dari 20" yang umum digunakan dalam dokumen cetak profesional.

Bisakah saya menambahkan nomor halaman ke beberapa file PDF sekaligus?

Ya. Pilih atau seret beberapa file PDF dan PDFree menomori halaman setiap file dengan format pilihan Anda, langsung di browser Anda. File yang telah diberi nomor dikemas dalam satu ZIP untuk diunduh. Tanpa unggah, tanpa batas harian.
