Pertanyaan yang Sering Diajukan

Apakah file saya diunggah saat mengedit metadata?

Tidak. Pengeditan metadata diproses sepenuhnya di browser menggunakan pdf-lib. File tidak pernah meninggalkan perangkat Anda.

Apakah PDFree menyimpan atau mencatat file saya setelah diproses?

Tidak. PDFree berjalan sepenuhnya di browser Anda — tidak ada server backend yang menerima file Anda. Karena tidak ada yang diunggah, tidak ada yang bisa disimpan, dicatat, atau dipertahankan. Dokumen Anda hanya ada di memori browser selama sesi berlangsung dan dihapus saat Anda menutup tab.

Bidang metadata apa saja yang bisa diedit?

Anda bisa melihat dan mengedit bidang metadata PDF standar: Judul, Penulis, Subjek, Kata Kunci, Pembuat, dan Produsen.

Bisakah saya menghapus semua metadata dari PDF?

Ya. Anda bisa mengosongkan bidang apa pun atau semua bidang sebelum menyimpan. Berguna untuk menghapus informasi pribadi sebelum berbagi dokumen.

Apakah ada batas ukuran file?

Tidak. PDFree tidak memiliki batas ukuran file atau jumlah halaman.

Apakah mengedit metadata mengubah konten PDF?

Tidak. Konten halaman, teks, gambar, dan tata letak tidak berubah. Hanya bidang metadata dokumen yang diperbarui.

Di mana metadata PDF disimpan?

Metadata disimpan di header dokumen PDF, bukan di halaman yang terlihat. Pembaca PDF seperti Acrobat menampilkan metadata ini di Properti Dokumen (Ctrl+D / Cmd+D).
