Frequently Asked Questions

Is my PDF uploaded anywhere when I add form fields?

No. Everything runs in your browser using pdf.js (to render the page you click on) and pdf-lib (to write the real AcroForm fields). Neither your original PDF nor the version with fields added is ever sent to a server. PDFree does not have access to your document.

What's the difference between this and the Fill PDF tool?

Fill PDF is for documents that already have interactive form fields — it detects them and lets you type values into them. Add Form Fields is for the opposite case: a flat or scanned PDF with NO interactive fields yet. You place the fields yourself by clicking on the page, then download a PDF that has real, fillable fields for the first time. If PDFree detects your upload already has fields, it will point you to Fill PDF instead.

Are the fields this tool creates 'real' form fields, or just boxes drawn on the page?

Real fields. Each placed box becomes an actual AcroForm text field written into the PDF's structure with pdf-lib — the same technology used to build interactive forms in Acrobat and other PDF authoring tools. Open the result in any standards-compliant PDF reader and you can click into the field and type, tab between fields, and the values are saved as real form data, not just an image.

What field types can I add?

Four types: text fields, checkboxes, radio button groups, and dropdown lists. Pick the type with the chips above the page, then click to place it. Text fields cover names, dates, addresses and free-text answers; checkboxes cover single yes/no ticks; a radio group is a set of buttons where only one can be chosen at a time; a dropdown offers a list of choices you type in yourself. Signature fields are not supported yet — use Draw on PDF to sign a document.

How do I place and adjust a field?

Choose a field type, then click anywhere on the rendered page to drop one at that spot. Drag the field by its round handle to reposition it, drag its bottom-right corner to resize it, and type directly into the field's own label to name it (helpful if you or someone else will later see field names in a PDF reader's form-filling sidebar). Click the small × button to remove a field you don't want.

How do I create a group of radio buttons where only one can be selected?

Pick the Radio field type and give the group a name in the Radio group name box, then click to place each option. Every button you place while that name is set joins the same group, so only one of them can ever be selected — which is what makes radio buttons different from a row of checkboxes. Type the option's own value into each button (for example Yes and No). To start a second, separate group, click New group and give it a different name. Editing the name while a placed button is selected renames that whole group instead.

How do I set the choices in a dropdown?

Pick the Dropdown field type and type the choices into the options box, separated by commas — for example Small, Medium, Large. Click on the page to place the dropdown, and those choices are written into the PDF as a real list a reader can open. Click an already-placed dropdown to load its choices back into the box and edit them.

Does this work on multi-page PDFs?

Yes. Use the page navigation above the preview to move between pages — fields can be placed on any page, and each page remembers its own set of fields. The Placed fields list beside the page shows every field you've added across the whole document, with its page number; clicking an entry jumps to that page and highlights the field, so you don't have to page through the document hunting for one.

Can I zoom in to place a field precisely?

Yes. Zoom controls sit next to the page navigation: zoom in or out in steps up to 400%, with a reset button to return to the default view. Zooming only changes how large the page is drawn on screen — fields are stored as positions relative to the page itself, so anything you've already placed stays exactly where it is on the finished PDF no matter what zoom level you place or review it at.

Can I add fields to a scanned PDF (a photo or scan of a paper form)?

Yes — this is exactly the case this tool is built for. A scanned PDF is just a picture with no interactive layer at all, so click-to-place lets you drop real text fields directly over where the printed blanks are, turning a scan into a fillable digital form.

Yes. Add Form Fields is completely free, with no account, no sign up, and no installation. Open the tool, load your PDF, click to place fields, and download — no email address required.
