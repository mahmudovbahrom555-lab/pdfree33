Edit PDF Metadata Online — Free, No Upload

View and edit the metadata embedded in any PDF: title, author, subject, keywords, creator, and producer. All processing happens locally in your browser — no file ever leaves your device.

Why Edit PDF Metadata?

Privacy: PDFs created by Word, LibreOffice, or Acrobat embed your name, company, and software version. Clear this before sharing externally.

Organisation: Set accurate titles and keywords so PDFs are easier to search and index in document management systems.

Publishing: eBooks and academic papers rely on correct author and title metadata for library catalogue entries and citation tools.

Are my files uploaded when editing metadata?
No. Metadata editing is processed entirely in your browser using pdf-lib. Files never leave your device.
Which metadata fields can I edit?
You can view and edit the standard PDF metadata fields: Title, Author, Subject, Keywords, Creator, and Producer.
Can I remove all metadata from a PDF?
Yes. You can clear any or all metadata fields before saving. This is useful for removing personal information before sharing a document.
Is there a file size limit?
No. PDFree has no file size or page count limits.
