O que é realmente comprimido em um PDF?

Entender isso é a chave para comprimir sem perda de qualidade. Um PDF contém dois tipos distintos de dados que se comportam de forma diferente sob compressão:

1. Texto e gráficos vetoriais — São descrições matemáticas (linhas, curvas, contornos de fontes). Não são afetados pelas configurações de qualidade de compressão. O texto em um PDF comprimido sempre ficará perfeitamente nítido, independentemente do nível escolhido.

2. Imagens raster (fotos, digitalizações, capturas de tela) — São grades de pixels armazenadas como JPEG ou PNG dentro do PDF. A compressão recodifica essas imagens com qualidade JPEG menor. É aqui que pode ocorrer perda de qualidade visível se a configuração for muito agressiva.

A implicação prática: se o seu PDF tem muito texto (exportações do Word, apresentações com poucas fotos), até a compressão "Baixa" produzirá um resultado visualmente idêntico. Se o seu PDF tem muitas digitalizações, use "Alta" para preservar a legibilidade.

Qual nível de compressão escolher?

Nível Redução de tamanho Qualidade da imagem Ideal para
Alta 20–40% Sem perda visível Digitalizações para impressão, fotos, brochuras
Média 30–60% Muito boa Anexos de e-mail, uploads web
Baixa 50–80% Reduzida Cópias de arquivo, rascunhos internos

Por que o texto sempre fica nítido, mesmo após compressão intensa

O texto em um PDF é armazenado como contornos de fonte (vetores), não como pixels. Quando o texto é renderizado em qualquer nível de zoom, a fonte é desenhada matematicamente naquela resolução exata — não pode ficar "borrada". Apenas as imagens JPEG incorporadas no PDF podem perder nitidez. Se o seu PDF é um documento de texto sem fotos ou digitalizações, você pode usar compressão Baixa sem nenhuma diferença visual — está apenas removendo metadados e estruturas de dados redundantes.

Perguntas frequentes

Quanto menor ficará meu PDF?
Depende do conteúdo. PDFs com muitas imagens podem ser reduzidos em 40–70%. PDFs só de texto geralmente se comprimem em 10–30%.
A qualidade do texto piora?
Não. O texto é armazenado como contornos vetoriais e sempre ficará perfeitamente nítido. Somente imagens incorporadas podem perder nitidez.
Meus arquivos são enviados para um servidor?
Não. Todo o processamento acontece no seu navegador. Seus documentos nunca saem do seu dispositivo.
Há limite de tamanho de arquivo?
Não. O PDFree não tem limites artificiais. A única restrição é a memória RAM disponível no seu dispositivo.
