Compress PDF Files — Reduce File Size Online

Large PDF files are slow to email, difficult to upload, and waste storage space. PDFree's compression tool reduces file size by removing redundant data and recompressing images — all without uploading your file to a server.

Three Compression Levels

Light: Removes thumbnails and metadata only. No image recompression — maximum compatibility. Typical reduction: 5-15%.

Standard (Recommended): Removes metadata + recompresses images at 82% quality. Balances size reduction with visual quality. Typical reduction: 30-50%.

Maximum: Aggressive image recompression (72% quality) + structure cleanup. Smallest file size, minor quality loss acceptable for most uses. Typical reduction: 50-70%.

When to Compress PDFs

  • Email Attachments: Most email providers limit attachments to 25MB. Compress before sending.
  • Web Publishing: Faster page loads mean better user experience and SEO.
  • Archival Storage: Save disk space on backups and cloud storage.
  • Mobile Sharing: Smaller files transfer faster over cellular networks.

What PDFree Removes

PDF files often contain hidden bloat:

  • Embedded Thumbnails: Page previews stored inside the PDF (Adobe Reader regenerates these anyway)
  • Duplicate Objects: Images or fonts used multiple times but stored redundantly
  • Metadata: Author names, creation dates, software version strings
  • Uncompressed Images: High-resolution photos that can be recompressed without visible quality loss

⚡ Photo PDFs: Documents with many photos (scanned images, photography portfolios) compress best. Text-only PDFs see minimal reduction since text is already efficiently encoded.

Edit PDF Metadata Online — Change Title, Author, Keywords

PDF files contain hidden metadata: title, author, subject, keywords, creation date, and software version. PDFree lets you view and edit all metadata fields, strip them completely for privacy, or export/import metadata as JSON for batch processing.

What is PDF Metadata?

Metadata is data about data. In PDFs, it includes:

  • Title: Document name (often different from filename)
  • Author: Creator's name
  • Subject: Brief description of content
  • Keywords: Searchable terms for document indexing
  • Creator: Software that produced the document (e.g., "Microsoft Word")
  • Producer: Software that generated the PDF (e.g., "Adobe Acrobat")
  • Creation Date: When the PDF was created
  • Modification Date: Last edit timestamp

Why Edit Metadata?

Privacy: Remove author names or company information before sharing documents externally. Strip creation dates that might reveal sensitive timing.

SEO: PDFs indexed by Google display metadata in search results. Optimized titles and keywords improve discoverability.

Organization: Add consistent author names, subjects, and keywords to large document collections for better searchability in file managers or document management systems.

Compliance: Some industries require specific metadata fields for document tracking, audit trails, or regulatory submissions.

Three Actions

🧹 Strip All: Removes all metadata fields. The PDF becomes anonymous — no author, no creation date, no software fingerprint. Useful before sharing confidential documents.

{} Export JSON: Saves current metadata as a JSON file. Useful for batch editing (modify JSON in a text editor, then import across multiple PDFs).

⬆ Import JSON: Loads metadata from a JSON file and applies it to the current PDF. Perfect for standardizing metadata across document series.

Metadata Removal vs. Content Redaction

Important distinction: Metadata removal only strips document properties. It does NOT remove watermarks, hidden text, or comments embedded in the PDF content. For full sanitization, combine metadata stripping with other tools:

  • Use Cover Area to hide sensitive text/images
  • Use Compress with "Remove thumbnails" to strip embedded previews
  • Review the PDF visually — metadata tools can't detect what's visible on the page

⚡ Forensic Note: Even with metadata stripped, PDF structure can reveal clues about creation software through encoding patterns. True anonymization requires regenerating the entire PDF, not just clearing fields.

Password Protect PDF Files Online — Secure with Encryption

Add password protection and usage restrictions to your PDFs. PDFree uses RC4-128 encryption (compatible with all PDF readers) to secure documents with a user password for opening and owner password for permissions. All encryption happens in your browser — your password and document never touch a server.

Two Types of Protection

Open Password (User Password): Required to view the document. Without this password, the PDF cannot be opened in any reader. Use this for truly confidential documents.

Owner Password (Permissions Password): Controls what users can do with the document even after opening. Restrict printing, copying text, editing content, adding comments, filling forms, or rotating pages.

You can set both passwords or just one. If you only set permissions without an open password, the document is viewable by anyone but usage is restricted.

Permission Control

Choose exactly what users can do:

  • Print: Allow or deny printing the document
  • Copy Text: Enable or block text selection and copying
  • Edit: Control whether content can be modified
  • Annotate: Allow or prevent adding comments, highlights, or notes
  • Fill Forms: Enable or disable filling interactive form fields
  • Assemble: Control page insertion, deletion, or rotation

Quick Presets

🔓 Open Only: Password required to open, but all operations allowed inside. Use when you want to control access but not usage.

📖 Read-Only: Users can view and print, but cannot copy, edit, or comment. Perfect for distributing reports or documentation you want read but not modified.

🏰 Fort Knox: Maximum restrictions. No printing, no copying, no editing. Useful for watermarked drafts or confidential previews.

Encryption Technical Details

PDFree uses RC4-128 encryption, the same algorithm used by Adobe Acrobat for decades. RC4-128 provides:

  • Universal compatibility: Supported by all PDF readers (Adobe Reader, Preview, Chrome, Firefox, mobile apps)
  • 128-bit security: Strong enough for most business and personal use
  • Fast processing: Encryption happens instantly in browser JavaScript

For context: 128-bit encryption means 2¹²⁸ possible keys (340 undecillion combinations). Even with modern computing, brute-forcing a strong password is computationally infeasible.

⚡ Password Strength: Use the built-in password generator (⚡ button) for cryptographically random 16+ character passwords. Store passwords in a password manager — if you lose the password, the PDF is unrecoverable.

Privacy & Security

Encryption happens entirely in your browser using pdf-lib's built-in RC4 implementation. Your password and document content never leave your device. This is critical — even HTTPS-encrypted transmission to a server means the server momentarily has access to your unencrypted file and password.

PDFree generates the encryption keys in-browser, encrypts the PDF content, and outputs a protected file directly to your download folder. No intermediate storage, no server logs, no password recovery system (because we never see your password).

Rotate PDF Pages Online — Fix Orientation

Fix incorrectly oriented PDF pages without re-scanning or re-creating the document. PDFree lets you rotate individual pages or all pages at once — 90°, 180°, or 270° (clockwise). Preview thumbnails before saving to ensure proper orientation.

How It Works

Click any page thumbnail and choose a rotation angle. The rotation is applied to the page's coordinate system — content, images, and text all rotate together as a unit. This is different from image rotation (which can degrade quality); PDF rotation is lossless and instantaneous.

Rotation options:

  • ↻ 90°: Rotate clockwise (portrait → landscape)
  • ↔ 180°: Flip upside-down
  • ↺ 270°: Rotate counter-clockwise (landscape → portrait)

Quick Selection Tools

For large documents:

  • Select All: Apply rotation to every page at once
  • Odd Pages / Even Pages: Rotate alternating pages (useful for double-sided scans where orientation alternates)
  • Undo / Reset: Revert changes and start over

Common Scenarios

Scanned Documents: Scanner feeds paper incorrectly, resulting in sideways or upside-down pages. Rotate after scanning instead of re-scanning hundreds of pages.

Mobile Phone Scans: Photos taken in landscape mode but interpreted as portrait (or vice versa). Batch rotate all pages to correct orientation.

Mixed Orientation Documents: Legal documents with some portrait and some landscape pages (like attached spreadsheets or diagrams). Rotate individual pages to uniform orientation.

PDF Form Filling: Downloaded forms sometimes have incorrect rotation. Fix before filling to ensure proper field alignment.

Technical Implementation

PDF pages have a /Rotate property that tells the viewer how to display the page. PDFree modifies this property directly — it's a metadata change, not a pixel-level transformation. This means:

  • Instant processing: Rotation is applied in milliseconds, even for 100-page documents
  • No quality loss: Text remains searchable, images stay crisp, no re-encoding
  • Small file size: The output PDF is the same size as the input (rotation adds ~4 bytes per page)

⚡ Preview Rendering: For documents under 30 pages, PDFree shows thumbnail previews of each page. For larger files, you'll see page numbers only (to save memory). The rotation still works the same way.

Redact PDF Online — Hide Sensitive Information

Permanently obscure sensitive information in PDF documents by drawing opaque rectangles over text, images, or data. PDFree's redaction tool covers content visually — perfect for sharing documents where certain information must remain confidential.

How Redaction Works

Drag across the PDF preview to select areas to cover. PDFree draws black (or custom color) rectangles over those regions. The rectangles become part of the PDF content — they cannot be removed or hidden to reveal underlying text.

Important distinction: This is visual coverage, not cryptographic deletion. The original content remains in the PDF file structure but is visually obscured. For most use cases (legal compliance, public records requests, privacy protection), this is exactly what's needed — the content cannot be seen or copied, but the document structure remains intact.

When to Use Redaction

Legal Documents: Obscure names, addresses, social security numbers, or account numbers before filing public court documents or responding to FOIA requests.

Medical Records: Remove patient identifying information to create de-identified records for research or case studies (HIPAA compliance).

Financial Statements: Hide account numbers, transaction details, or balances when sharing bank statements for loan applications or background checks.

Business Contracts: Redact pricing, terms, or confidential clauses when sharing contract templates or portions with third parties.

Government Documents: Public records officers use redaction to protect privacy while releasing information under transparency laws.

Usage Instructions

  1. Upload the PDF — a preview renders in your browser
  2. Click and drag to draw a redaction rectangle over sensitive text or images
  3. Repeat for all areas needing coverage (up to 5 areas per page to prevent accidental over-redaction)
  4. Click "Clear all" if you need to start over
  5. Download the redacted PDF — black rectangles are now permanent

Security Considerations

What Redaction Does:

  • ✅ Prevents visual viewing of covered content
  • ✅ Prevents text selection/copying of covered content
  • ✅ Works in all PDF readers (rectangles are standard PDF drawing objects)

What Redaction Does NOT Do:

  • ❌ Does not delete content from the PDF file structure (forensic tools can extract underlying text)
  • ❌ Does not remove metadata (use Metadata tool separately)
  • ❌ Does not prevent determined adversaries with specialized software from accessing original content

⚠️ Legal Redaction: For documents subject to legal proceedings or classified information, consult your compliance or legal team. Some jurisdictions require certified redaction tools that cryptographically delete content. PDFree provides visual coverage suitable for most business and privacy use cases but is not certified for classified government documents or high-security legal contexts.

Privacy & Processing

Your PDF never leaves your browser. The redaction rectangles are drawn using pdf-lib's content stream API — all processing happens locally in JavaScript. No server sees your sensitive document or learns what you chose to redact.
