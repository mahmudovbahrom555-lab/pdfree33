## Core Phrases

| English | Korean | Notes |
|---------|--------|-------|
| Free | 무료 | Never 공짜 |
| No upload | 업로드 없이 | Standard |
| No registration | 회원가입 없이 | Never 등록 없이 or 불필요 |
| Without limits | 제한 없이 | Never 무제한 (sounds like a pricing tier) |
| Processed in browser | 브라우저에서 처리됩니다. | Full sentence, not 로컬 처리 |
| Files never leave your device | 파일은 기기를 떠나지 않습니다. | Natural, not 파일이 기기를 벗어나지 않습니다 |
| Online | 온라인 | |
| Safe | 안전하게 | |
| Fast | 빠르게 | |
| Choose file | 파일 선택 | Never 파일 고르기 |
| Drag PDF here | 여기로 PDF를 끌어오세요 | Natural |
| Preview | 미리보기 | Never English "Preview" |
| Download | 다운로드 | OK to keep as-is |
| Cancel | 취소 | |

## H1 Pattern

```
{Tool name} — 무료, 업로드 없이
```

Examples:
- PDF 합치기 — 무료, 업로드 없이
- PDF 압축 — 무료, 업로드 없이
- PDF 암호 설정 — 무료, 업로드 없이

## FAQ Style

Short, conversational questions (how real users search):
- 무료인가요?
- 회원가입이 필요한가요?
- 파일이 서버로 업로드되나요?
- 아이폰에서도 사용할 수 있나요?
- Mac에서도 사용할 수 있나요?
- 100개 이상의 PDF도 합칠 수 있나요?
- 암호가 있는 PDF도 지원하나요?
- 하루 사용 횟수 제한이 있나요?

## Do Not Translate

These stay in Latin script:
- PDF
- JPG, PNG, WEBP
- OCR
- AES-256
- Web Worker

## Content Style

Short sentences. Modern Korean SaaS style:

✅ Correct:
```
PDF를 브라우저에서 바로 처리합니다.
업로드가 필요 없습니다.
회원가입도 필요 없습니다.
파일은 기기를 떠나지 않습니다.
```

❌ Avoid:
```
이 도구를 사용하면 PDF 파일을 업로드하지 않고도 브라우저에서 직접 처리할 수 있습니다.
```
