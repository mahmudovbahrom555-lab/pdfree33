Frequently Asked Questions

Are all PDFree tools completely free?

Yes. All 18 tools are free with no file count limits, no daily task limits, no file size limits, and no paid plan. PDFree is an open-source project built for everyone.

Do PDFree tools upload my files?

No. Every tool processes files locally in your browser using JavaScript. Your files never leave your device and are never sent to any server — making PDFree safe for sensitive and confidential documents.

Do the tools work offline?

Yes. After your first visit, PDFree caches all tools locally as a Progressive Web App (PWA). You can process PDFs without an internet connection — even after installing it from your browser.

Is there a file size limit?

No software limit. The practical limit is your device's available RAM. Most modern computers handle PDFs up to several hundred megabytes easily. Merge and Split have been tested with files over 1GB.
