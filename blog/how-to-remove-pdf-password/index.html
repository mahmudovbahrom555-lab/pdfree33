How to Remove a Password from a PDF
(Free, No Upload)

3-minute read · Updated June 2026

Have a password-protected PDF you want to unlock? If you know the current password, you can remove it instantly — for free, without uploading the file anywhere. Here's the step-by-step method.

Important: PDFree can remove a PDF password only if you already know the current password. This tool is for removing protection from your own documents — not for cracking unknown passwords.

Step-by-step: remove a PDF password using PDFree

  1. 1
    Open PDFree Protect — no login needed

    Go to pdfree.io/protect-pdf/. This tool both adds and removes PDF passwords.

  2. 2
    Add your password-protected PDF

    Click "Choose files" or drag your locked PDF onto the page. The file is loaded into browser memory — not uploaded to any server.

  3. 3
    Enter the current password — leave the new password blank

    Type the existing password in the password field. Leave the "new password" field empty. This tells the tool to save the PDF without any password protection.

  4. 4
    Click "Protect PDF" and download

    The unlocked PDF downloads to your device. Open it in any PDF viewer — no password prompt will appear.

Common reasons to remove a PDF password

  • Editing a protected document: You received a password-protected PDF and need to compress, merge, split, or otherwise modify it — PDFree cannot process encrypted PDFs, so unlock it first.
  • Archiving without password overhead: You encrypted a document for sending but want to store an unlocked copy in your own archive for easy access later.
  • Sharing with a team: A document was password-protected for one recipient but now needs to be shared more broadly without the extra step of providing a password each time.
  • Printing: Some PDF password settings restrict printing. Remove the password to print without restrictions.

Is it safe to unlock a PDF on a website?

With most online PDF tools: no. They upload your document (and your password) to their servers. Your locked file and secret password are both transmitted to a third party.

PDFree is different. The entire unlocking process runs in your browser. Your PDF and your password are never transmitted anywhere. This is not a privacy policy claim — it is structural: PDFree has no server-side PDF processing. You can verify this in the open source code (GNU AGPLv3).
