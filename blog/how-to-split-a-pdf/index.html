Three ways to split a PDF in PDFree

PDFree's Split tool gives you three approaches depending on what you need:

  • Custom page range — Type 1, 3-7, 12, 15-20 to select specific pages. Combine with clicking thumbnails. Get selected pages as one PDF or as separate files in a ZIP.
  • All pages individually — Split every page into its own PDF. Downloads as a ZIP archive with files named page-1.pdf, page-2.pdf, etc. No page limit.
  • Odd / Even pages — One click selects all odd-numbered or all even-numbered pages. Useful for separating front and back sides from a flatbed scanner or extracting alternating pages from a duplex print job.

Common split scenarios and how to handle them

📋 Extract a chapter from a book or report

Select the page range for the chapter (e.g., 22-31), choose "Single PDF", and download. The result is a standalone PDF containing just those pages.

🖨️ Separate front and back from a flatbed scan

When scanning double-sided documents on a single-sided scanner, odd pages are fronts and even pages are backs. Use the "Odd pages" quick-select to get all fronts in one ZIP, then "Even pages" to get all backs.

📧 Break a large PDF for email

A 40 MB PDF over Gmail's 25 MB limit. Split into first half and second half — two ~20 MB files — and send in two emails. The recipient can merge them back with PDFree Merge.

📂 Separate invoices from a combined PDF

A statement PDF with 12 invoices, 3 pages each. Split into groups of 3: 1-3, 4-6, etc. Download each as separate PDF files.

Split vs Extract — which should I use?

PDFree has two tools that do similar things:

  • Split — Powerful. Select any pages, get one PDF or multiple separate files in a ZIP. Use this when you need multiple output files or complex page selections.
  • Extract — Simpler. Pull a single page range into one new PDF. Use this when you need exactly one chunk of pages from a document.
